# 归园 · 放逐小镇（Banished 复刻原型）

一个零依赖、纯前端可玩的《放逐之城》(Banished) 风格城市建造游戏原型。
等距视角、市民 AI、四季轮转、食物/木材/石头/柴火经济，**所有经济数值对齐原版 Banished**。

## 运行

无需构建、无需依赖：

```bash
# 方式一：直接双击 index.html 用浏览器打开（file:// 即可）
# 方式二：本地服务器
python3 dev-server.py 8613     # 禁用缓存的开发服务器
# 打开 http://localhost:8613
```

## 部署到服务器（收集试玩反馈）

零依赖、无需数据库，一个 Python 标准库脚本搞定静态托管 + 反馈落盘：

```bash
# 把 index.html / style.css / js/ / server.py 上传到服务器任意目录
python3 server.py 8613                    # 绑定 0.0.0.0，浏览器访问 http://服务器IP:8613
nohup python3 server.py 8613 > server.log 2>&1 &   # 或用 systemd 常驻
```

**反馈入口**：游戏右上角 📮。玩家**无需注册**，一句话反馈 + 可选昵称，勾选后自动附带当前存档快照（仅游戏数据），提交后即可在服务器上查看：

- 反馈存储：`feedback/feedback-YYYYMM.jsonl`，每行一个 JSON（正文、昵称、进度摘要、存档快照、脚本错误、匿名玩家 ID、IP 盐值哈希）。
- 在线查看：`FEEDBACK_TOKEN=私密token python3 server.py 8613` 启动，访问 `http://主机:8613/api/feedback?token=私密token`；不设 token 则该接口关闭，直接 ssh cat 文件。
- 防滥用：每 IP 每 10 分钟最多 6 条；单条 ≤1.5MB；月文件超 50MB 拒收；目录列表禁用。
- 反代（可选）：nginx `location / { proxy_pass http://127.0.0.1:8613; }`。

注意：file:// 或接口不可用时，前端自动降级为「复制反馈内容手动发给开发者」，不会丢反馈。

## 操作

| 操作 | 功能 |
|---|---|
| 左键 | 建造 / 选择（无工具时拖动可平移视角） |
| 右键拖动 | 平移视角；右键点击 = 取消当前工具 |
| 滚轮 | 缩放；WASD / 方向键平移 |
| 空格 | 暂停；1 / 2 / 3 = 1x / 3x / 8x 速度 |
| Esc | 取消工具 / 取消选择 |

💾 保存 / 📂 读取 = localStorage 手动存档；🌱 新游戏随机地图。
**存档管理（📂）**：面板中可查看、载入、删除「手动档」与「自动档」（含一键**清空全部存档**，带确认，不影响当前对局），显示存档时间和游戏内进度。
**自动存档**：每个季节更替、每 90 秒、切走标签页、刷新或关闭页面时自动写入「自动档」；下次打开自动恢复（结算后死档不恢复；🌱 重开会清除旧自动存档）。

## 系统概览

- **时间**：1 年 = 48 天（春夏秋冬各 12 天），1x 速度 1 天 ≈ 12 秒。
- **市民**：A* 寻路（道路加速）、作息节律（22 点回家睡觉、6 点起床）、工作/搬运/进食/取暖状态机、家庭与生育、饥饿/受冻/衰老死亡。
- **教育**：学堂开学后孩子 10 岁入学、16 岁毕业；受教育工人干活更快（伐木屋 1 原木出 4 柴火），学生不占劳动力。
- **林业**：护林小屋面板可分别开关「砍伐 / 补种」（原版 Forester 的 Cut/Plant）；伐木屋两段式干活——工人自己走去仓库背原木、回屋劈柴、再送柴火，挨着仓库建更快。
- **标记砍伐**：「砍伐」工具点击/框选任意树木（原版 Harvest Trees），无业散工前来砍倒，每次 2 原木入库；清场开田不再依赖护林小屋。
- **劳动力自动调度**：工地 > 工作岗位；工地可从普通岗位抽人（教师除外）；粮食岗位按人口保底；春夏农田工人自动流转去伐木备柴，秋收自动回流抢收。
- **季节**：植被换色、冬季降雪、房屋窗户透光、炊烟；未收获的农田作物会被冻死。
- **失败/胜利**：全员死亡即结算；活下去、多生娃就是胜利。

## 代码结构

```
index.html      UI 骨架 + 错误收集
style.css       深色木质 HUD
js/core.js      常量 / RNG / 工具
js/defs.js      建筑定义 / 产出参数 / 季节调色板（原版数值都在这）
js/map.js       地形与岩石生成 / 树木 / A* 寻路 / 放置判定
js/sim.js       时间 / 市民 AI / 劳动力调度 / 经济与生死
js/render.js    等距渲染（地面缓存 / 建筑 / 市民 / 粒子）
js/ui.js        HUD / 建造菜单 / 信息面板 / 通知
js/feedback.js  匿名试玩反馈（📮，无需注册）
js/main.js      游戏循环 / 输入 / 存档
dev-server.py   开发用禁缓存静态服务器
server.py       部署服务器：静态托管 + /api/feedback 反馈落盘
tests/          冒烟测试（node tests/smoke.js · python3 tests/server_smoke.py）
```

零依赖纯 Canvas 2D，`file://` 双击即玩。

## 已验证

- 标准开局脚本模拟两年：**15 人全员穿过两个冬天、0 死亡、2 名新生儿、4/4 家庭有房、森林因补种持续增长**。
- 护林小屋可持续产能实测 **~109 原木/所/年**（原版社区基准 ~120，3 张地图各一年）。
- 「砍伐」标记工具：框选后散工自动前往砍倒，一人一树、跨夜续接、2 原木入库。
- 存档/读档完整还原（含树木、岩石清理记录）。
- `node tests/smoke.js`：经济/作息/教育/存档 39 项断言；`python3 tests/server_smoke.py`：静态托管、反馈落盘、限频、token 鉴权 10 项断言。
