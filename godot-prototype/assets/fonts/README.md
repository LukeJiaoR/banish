# Font provenance

`jade-song.ttf` is the existing `../../../assets/fonts/jade-song.woff`
decompressed with FontTools (`TTFont`, `flavor = None`, `save`). Glyph outlines
and the family are unchanged. It is bundled only because Godot's native font
import uses TTF/OTF rather than the original browser WOFF container.

The original Noto font license is copied beside it as `LICENSE-Noto.txt`.
No system font is copied and no paid font is downloaded. Normal project use
does not need Python or FontTools.
