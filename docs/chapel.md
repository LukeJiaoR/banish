# 礼拜堂与真实礼拜（0.3.63）

## 先有余粮，再安排精神生活

城镇服务新增3×3礼拜堂，建造消耗50原木、130石、30铁与150劳动，沿用正常清场/施工/暂停/取消。1名健康、未饥饿牧师须走到真实入口才开始服务；在途、患病、饥饿、夜休或用工上限为0都不算在岗。礼拜堂有可见的真实劳动和昂贵建材成本，不生产资源，也不需要麦酒。

居民在手头任务结清、无携货、未生病/饥饿/明显受冻时，才考虑步行礼拜。全村可用分布粮少于8天不接新行程，已接行程也会停止；医疗、家庭采购、补工具和建筑施工优先。教师在有学生时、需要照料病人的医生以及牧师不离岗去礼拜。儿童可参加，在读学生必须完成当日6小时或所有毕业课时才参加，不因新增服务逃课。

只考虑24格以内、预计单程不超过6小时且真正可达的礼拜堂。每馆最多8人在途或到场预约；至多200名尚有本馆礼拜记忆或正在预约的居民，二者去重。这是服务覆盖人口，并非200人同时挤在建筑里。记忆到期或人死亡释放覆盖名额；取消未完成行程释放预约。满堂时会尝试另一所可达礼拜堂。

## 真实到场才获得幸福

居民与牧师共同在场后，累计2小时礼拜，时间不受教育、工具、幸福等劳动倍率加速。完成时幸福即时+0.2（最高5），并获得6天礼拜记忆，使现有幸福目标+0.5。与酒馆记忆可以并存，幸福总上限仍为5，原有正向劳动效率最高+5%的规则不变；它不保证付出的路程和服务时间能净增产。

牧师临时离岗则暂停计时，最多等待4小时；断路、拆堂、停用岗位、夜间、疾病或生活告急会取消未完成礼拜，不赠送记忆。工作人员和访客真实到达后按室内服务隐藏地图人物，避免在门前播放砍树动作；外出仍沿用现有人物行走图。详情面板分别显示牧师在岗、覆盖名额、预约/在场/在途及当前等待原因。

## 存档和旧村

只持久化已经获得的礼拜记忆和来源建筑。日终记忆减少，到0清空来源。中途存档沿用项目任务重启合同，不保存尚未完成的礼拜工时、不补发幸福。旧档缺少字段按0/无来源处理，不自动建堂、不扣旧资源，也不改变已有幸福。

拆除礼拜堂取消在途服务；已完成记忆自然保留至到期，来源清空，不能再次进堂刷新。非法天数、非礼拜堂来源和超过200名的服务记忆拒绝导入，当前村庄保持不变。

## 原版依据与本作适配

- [Chapel](https://banished-wiki.com/wiki/Chapel)：1名牧师、最多200名居民、幸福服务；建材为50木/130石/30铁，劳动150。资源图标对应关系已在原页面核实。
- [Cleric](https://banished-wiki.com/wiki/Cleric)：每堂恰好一个职业名额。
- [Citizens / Happiness](https://banished-wiki.com/wiki/Citizens#Happiness)：满足生活与服务需求影响幸福，幸福影响劳动。

3×3占地、8人预约、2小时服务、6天记忆、0.2即时/0.5目标幸福、短途和保粮/课业限制、覆盖按记忆统计是本作小地图适配，不宣称复刻原版全部数值。没有引入宗教类型、全镇远程光环或新的资源统计体系。
