## 参考与未采用试验

## 版本与采用规则

[机器可读清单](manifest.json)记录稳定 ID、版本、来源、SHA-256、决策状态、获准范围及限制。采用状态必须跟随用户实际决定，不能因生成、入库、合并或提示词措辞自动升级。新版本另存并关联旧 ID；不得覆盖 A 原图或抹去历史决定。

Library 中同步分为“已采用视觉基准”“待评审概念稿”“参考与未采用试验”；移动归类保持既有稿件身份。归档不是生产发布，也不表示 #87 已完成。
