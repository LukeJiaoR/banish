# 铁匠取料与工具物流（0.3.43）

## 玩家能做的布局选择

铁匠不再站在屋边直接扣全镇铁木煤。工人先按真实加权道路到可达、兼容全部原料的堆料场或通用仓库，再携带原料回铁匠铺加工，最后把工具送到通用仓库。堆料场不收工具；石路与靠近工坊的堆料场可减少原料往返。

仍是公共库存模型：仓点没有各自独立的库存数量，在任何兼容仓点都可取用公共材料。没有新增跨仓调拨或市场/家庭储粮系统。旧档完全没有任何仓点时，保留在铁匠入口取用虚拟公共库存的兼容分支；正常村庄不会触发。

## 一批材料的明确归属

- 铁工具：1铁+2木 → 2件，受教育铁匠3件；钢工具另需2煤。1名铁匠、基础4小时锻造，既有健康/幸福工时与教育产量规则保留。取料核对需0.1游戏小时。
- 接任务时冻结本批配方、产物与工时。取料前仍未扣资源；到了真实仓点，且有返回工坊的通路、整套原料充足，才同步一次扣出整批。缺任一项不会先扣掉其他材料。
- 已取铁、木、煤成为同一受保护随身货批，公共库存立即减少，其他工坊与住宅不能重复使用。锻造完成只替换这批材料为工具，不再次扣库存。
- 切配方/目标不改旧批次。用工上限调0先完成已接批次与送仓，再释放岗位，恢复/再次调0不复制材料。
- 工人离开真实工作入口，需重新寻路到入口后才继续工时；邻建挤人不能隔空锻造。取料/回屋途中封路会放弃加工并退回原料，按现有2小时重试节流寻找兼容仓点。
- 拆工坊、任务中断或读档后，未消耗的原料退仓。满仓、部分仓位、暂时无路时逐项保留原料，等腾出空间/恢复通路后交清。最后卸净才清除本批保护标记，不传给之后普通货物。
- 这不是生产收益：材料往返不会产生额外铁木煤。现有死亡丢失随身货物规则未改；本片没有引入死亡货物回收系统。

## 界面与存档

建筑详情显示公共可用原料（不含已出库批次）、本批原配方、待取/返屋/加工/夜间暂停/退仓状态，以及全部随身铁木煤。居民详情也显示整批数量，地图携带图复用已有铁料/木料/煤和工具图，不把一张图标解释成只有一种材料。

沿用现有存档只保存库存、岗位、实际携货，不保存完整任务/工时/路径的合同。新增货批标记只允许受保护的有限铁木煤批次；数量、类型、重复主副项或不匹配标记拒绝导入，当前村庄不被覆盖。保存本身不扣料、消料、退款或生成工具。读档无法复原的未完加工被放弃，实际随身原料退仓，之后重新接批次。

旧存档未取料任务无需迁移，因为旧版本原料未在完成前扣除，任务也未存入档。已有普通工具/原料库存、矿种、工具耐久、煤补柴底线和裁缝/伐木屋原有扣料时点不变。

## 原版依据与适配

[Blacksmith (Building)](https://banished-wiki.com/wiki/Blacksmith_(Building)) 的 Efficiency 段明确铁匠往返堆料场补原木/铁/煤、送工具入仓，距离与道路影响效率。本片实现这一实际物流缺口；本作1铁2木、钢再2煤、2/3件产量、4小时工时与公共库存均为既有适配，不宣称原版精确数值。
