# 果园整园砍树与换种

关联跟踪 #139；本次仅实现整园砍树，提前采收仍未实现。当前果树仅在秋季生成果实；本次不新增提前结果、不凭空产生果实。

## 操作与 A 界面

沿用原果园详情、原树位与素材。展开“整园砍树换种”，明确选择清空后补种的已解锁品种，或“留空，不补种”；确认不可恢复的树和树上果实损失后下达。逐树列表显示待砍/空位，指令显示剩余株数、树上果实、后续品种；在途行同时显示实际携果和原木。

清园指令期间，普通收果、种植与养护停止，另行改补种设置被拒绝。暂停仍保留指令，取消恢复原先补种设置；两者都清除未完成的砍树工作，不撤回已采果或已砍木。砍树全部结束（含最后一株自然老死）后才应用明确选择的补种安排。

## 实际劳动与适配规则

农夫须到实际树位完成劳动；沿用森林砍树工时和教育/工具产量规则。只有派工时已成熟的树有原木，幼树清除不产木；这是本作适配，不声称是原版果园数值。派工遵守原木目标和可用仓容。已开工批次可完成，满仓时保留实际携货等待；不远程入库。

完成时替换单株状态、增加更新次数并一次产生携货，树上果实随清除损失。任务必须仍持有当前清园指令、同一树对象和更新次数；暂停/取消/失业/死亡使旧任务无效。已有携果不变种、不丢弃。固定场和旧面积场使用原树位布局。

## 存档边界

可选建筑字段 `orchardCut: {type, paused}` 保存指令，type 为已解锁的 legacy/apple/pear 或 none。缺字段即无指令，旧村不自动启用、不迁移库存；现有 v1–v7 格式编号不变。仅建成果园且仍有种植树的逐树存档可携带该字段，严格拒绝多余字段和无效品种/暂停状态。实际木材沿用 orchardId 货批标记并限制其数量；加载恢复实际树与携货，不生成产量。未完成工作不保存劳动进度，重派后重新劳动。

新增指令是可选格式扩展，不可安全回退旧程序：旧程序可能忽略清园指令，且旧加载器拒绝带 orchardId 的木材。请用本次或更新版本读取执行清园后的存档。
