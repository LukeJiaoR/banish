# 木屋原地改建石屋（0.3.35）

> 0.3.71 起的新工地使用 [建材实运](construction-delivery.md)：放置不预扣/预留库存，到仓领取才扣，齐料到场后施工；已付旧工地保留原进度和退款合同。本文历史付款说明以该增量为准。

## 为什么升级

木屋与石屋仍分别可直接建造。已有木屋现在也可在详情中原地改建为石屋：不增加占地、不凭空新增家庭，但已有一家人的整冬柴火需求可从约 30 降到 15。这个一半省柴比例沿用本作现有数值，并非声明 Wiki 原版精确比例。

先查看报价、住户人数、全镇备用住房与冬季风险，再点确认开始。第一次点「升级」只展开确认，取消确认不会改资源、住户或建筑。升级是拆除旧木屋再真实建造，不是瞬间变成暖房。

## 材料只投入一次

标准木屋曾支付 16 木＋8 石，改建时回收其中一半，即 8 木＋4 石，并直接投入新石屋。

- 石屋完整投入：24 木＋40 石＋10 铁。
- 旧屋回收：8 木＋4 石。
- 全镇库存实际补付：16 木＋36 石＋10 铁。

旧档按原木屋成本认定旧投入；带付款快照的木屋按实际付款计算，免费放置的木屋没有可回收材料。回收受原木屋成本上限限制，不从新库存凭空加一笔再扣另一笔。所有补料齐备、且至少一位非学生成人可到达施工入口时才可开始；不能先扣一部分资源再因缺料失败。

新石屋工地的已投材料包含旧材与补料共 24/40/10。未开工就取消，按现有工地规则退回完整投入：相对于升级前，最终相当于拆了木屋并得到 8 木＋4 石回收。开工后取消或完工后拆除，只退完整投入的一半。取消会移除工地，不恢复旧木屋；重复旧回调不能多退材料。

报价确认会重新校验建筑身份、材料、住户、备用住房及冬季风险。发生变化需重新查看，不能凭旧确认升级新加载村庄中的同 ID 房屋，也不能对同一木屋重复收费。

## 住户与施工

开始后，同一地块、同一建筑 ID 变成石屋工地，住户立即腾空，家庭 ID 与亲属关系保留。沿用已有住房分配：有空独栋优先入住，没有则使用宿舍；都没有时家庭处于无房状态。全镇空屋与宿舍空位是实时总数，不代表已预留或承诺所有家庭成员都能到达，路线仍影响实际回家。

在走向旧木屋或已在旧屋休息的住户会重新处理回家路线，不能继续把新工地当暖屋。正在生产/搬运的居民保留原任务与携货。直接取消改建工地时，被释放建筑工当前已携货批次也会保留；退款填满仓库时先等待空间，跨夜或读档不吞掉余货，卸净后标记随当前货物清除。这只覆盖该改建工地取消释放的现货，不改变普通采集既有满仓规则。铁/钢工具仍沿用原有无硬仓容合同，保全工具货批不会被普通仓容错误卡住。无房家庭的寒冷风险真实存在，尤其冬季；升级前请准备临时住所和柴火。新屋完工后按正常住房规则安排家庭，已另有独栋的家庭不会被强制搬回。

施工使用现有建筑工、工作时段和真实 120 基础工时，不免费瞬间完工。可以暂停/恢复，已完工段与已投材料保留，未完小工段按原暂停规则重新开始；恢复不再次扣料。未完工石屋既不能住人也不能供暖。

## 保存、美术与依据

保存改建来源、工地进度、材料投入与暂停状态；住户暂住状态沿用既有家庭存档。旧档木屋不会自动升级，普通石屋也不凭空变成改建项目。非法改建来源在读取候选存档时原子拒绝，不改变当前村庄。

复用已有木屋、2×2 工地与石屋原创素材，按实际状态切换，无新生成图片，也不改变用户统一的透视、比例或配色。

[Banished Wiki Housing / Stone House](https://banished-wiki.com/wiki/Stone_House) 描述木屋可原地升级石屋、回收部分材料，施工期间住户搬出，冬季无备用住房存在受冻风险。本片继承这条发展选择；材料即时核销、既有住房自动分配和省柴比例保持本作适配。
