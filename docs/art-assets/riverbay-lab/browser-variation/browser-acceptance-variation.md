状态：**结构、交互与稳定性通过浏览器验证；美术不通过（湿沙/浅水过淡，窄处没有滩）；首帧比 A 多 13–30ms；真机未验收。** 保持 Draft，不启用正式入口。

对象：`a881872`（`shoreVariation=true`，默认关闭）。A 为 `2857b94` 结构版，同一页面内逐项切换，只有第五个开关不同。前两轮浏览器记录保留在 `../browser/`、`../browser-fixed/`，未覆盖。

## 环境与方法

- macOS Chromium（ego-browser），真实页面 `http://127.0.0.1:8627/riverbay-lab.html`，`python3 dev-server.py 8627`。
- 桌面：画布 1200×521 CSS，DPR 1；窄屏：CDP `Emulation.setDeviceMetricsOverride` 390×620、DPR 2。**不是实体手机。**
- A/B 全部同相机：相机只设一次，之后仅切 `shoreVariation`；对照图直接取 `G.cv.toDataURL()` 的画布像素，不掺页面边框缩放。
- 缩放 0.75/1/2；四个预设；开关单独切换；拖动 27 秒（rAF 驱动合成 pointermove）；`window.__errs` 全程为空。
- 计时取 `metrics().profile.operations` 最近一条 `setOptions` 的 `totalSyncMs` / `frameSyncMs`；暖帧为连续 40 次 `render()`。

## 美术结果

**等宽描边感确实减弱了**：宽度按 22/26 格正弦变化，岛屿北端收窄到几乎没有、南端明显变宽；`compare-island-z2.png` 里 A 是一条等宽沙带，B 的宽度沿程变化，不再是“手绘描边”。

**但湿沙和浅水层次偏淡，窄处直接消失**，原因是两处叠加：

1. 核心不透明度只有 A 的一半：A 陆侧 `rgba(151,140,100,.65)` 25px + `.35` 10px；B 核心 `.30`、外层 `.14`、内层 `.20`。水侧 A `.52/.28`，B `.25/.12/.17`。
2. 宽度下限 4px（水 6px），窄相位上几乎没有滩；0.75 倍下 `compare-z075.png` 的村庄岸线已经是草直接接水，只剩一条浅线。

颜色变化在单个视口里基本看不出来：渐变周期 38 格（1 倍下约 2400px），一屏只覆盖半个周期，所以观感差异主要来自宽度。差异热力图 `diff-island-z2.png` 显示变化严格限制在岸带（2 倍下 15.1% 像素），草地、树、建筑逐像素完全一致。

结论：方向可用，但这一版把“等宽描边”换成了“窄处没滩”。要继续，建议同时改三点——核心透明度提到 `.45–.5`、宽度下限提到 8px 左右、颜色周期缩到 12–16 格；湿沙最靠水的一侧应更深，而不是更淡。

## 首帧与暖帧

同一页面、逐个切换，A/B 各两次：

| 缩放 | A（study） | B（variation） |
|---|---|---|
| 1.0 | 32.4 / 34.7 ms | 59.0 / 65.4 ms |
| 2.0 | 36.2 / 36.9 ms | 56.0 / 56.6 ms |
| 0.75 | 29.5 / 32.5 ms | 42.2 / 56.3 ms |

B 的首帧比 A 多 **13–30ms**（约 1.4–1.9 倍），60fps 下相当于多 1–2 帧；耗时几乎全在 `frameSyncMs`，`buildGround` 段仍是几毫秒。

暖帧 40 次 `render()`：p50 `0.3ms`、p95 `0.6ms`，单次最高 `60.5ms`（一次性尖峰，与 A 同类）。稳态开销可忽略。

## 27 秒连续拖动

合成 pointermove 每帧一次，记录每次 `render()` 同步耗时：

| | A | B |
|---|---|---|
| 采样帧 | 477 | 410 |
| p50 | 1.6 ms | 1.9 ms |
| p95 | 17.1 ms | 17.9 ms |
| p99 | 53.2 ms | 57.6 ms |
| >16.7ms | 26 | 22 |
| 最高 | 768.8 ms | 1387.5 ms |

B 的稳态分位与 A 基本重合（p95 +0.8ms）。两种版本都出现 0.8s / 1.4s 级尖峰，属于本机无头会话的环境抖动，不能记到 B 头上。该会话的 rAF 被节流到约 15–18Hz，**帧数不能换算成 FPS**，只有单次耗时可比。

## 交互与稳定性

- 单独切 `shoreVariation` 且 `shore=false`：**0 次地面重建**，符合“需岸线”约定；冬季 `shore()` 提前返回，同样不生效。
- 拖走再拖回同一相机：画布像素**逐字节一致**（最大差 0），说明岸带宽度/颜色按世界坐标锚定，不随平移重新随机。
- 窄屏 390×620：控件换行正常，画布 390×370，页面 390×800，无横向溢出，无报错。
