# 第一批：树素材清理、树石有限变化、人物可读性

状态：**可用候选，未合并。** 只改渲染与三张/六张树 PNG 的透明像素，不动碰撞、寻路、任务、存档和玩法数值。

## 做了什么

1. **树素材清理**：`tree_mature` / `tree_young` 的原图左上、右上角各粘着草石残片（透明通道上是独立连通块）。按 alpha 连通块只保留主体，清掉 `mature` 3,174px、`young` 430px；`sapling` 和三个雪版只剩 1–11px 噪点，一并清掉。画布尺寸不变，脚点对齐不变。
2. **树的有限变化**：只加尺寸，`0.94–1.06`，由 `G.h2(mapSeed + 7, x, y)` 决定，同一棵树每次重绘、读档、平移后都一样。**没有**做横向抖动和翻转：翻转会把烘焙光照和脚下阴影一起镜像，原图边角残片也会跟着翻；抖动则要同步改深度排序。两者留到素材重绘后再做。
3. **石头**：原来的 `((x*7+y*13)%2)` 是严格棋盘，改成同一套稳定哈希选 `rock_a` / `rock_b`，尺寸 `0.9–1.1`。石头烘在地面缓存里，只改绘制参数，缓存结构和裁切不变。
4. **人物可读性**：新增 `G.sprDrawRim()`，用四次零模糊 offset shadow 在精灵外沿描一圈 `rgba(22,16,9,.35)` 的 1 CSS px 暗边，再正常绘制一次；偏移按 `G.dpr` 缩放，Retina 上不会变成半像素。同时把脚下阴影从 `3.4×1.7 / 25%` 收到 `2.9×1.5 / 30%`，少一圈“水洼”。每帧每个可见村民多 4 次小图 drawImage，没有离屏缓冲。
