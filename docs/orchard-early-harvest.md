# 果园提前采果：来源、适配与存档

关联跟踪 #139。提前采果是原版已有功能；本次按来源补齐，不实现绕过食物上限的抢收。

## 原版证据

[官方工具包页面](https://shiningrocksoftware.com/game/mods/)提供 [1.0.7.170910 原版资源包](https://shiningrocksoftware.com/download/BanishedKit_1.0.7.170910.zip)。所依据的是 resource 下原版资源，不是 example 中的模组。

- Game/Help/Orchard.rsc：果园秋季或果实成熟自动收获，可通过 Harvest 提前采果；农夫实背送仓；食物上限仍有效。
- Game/Scenario/TutorialFood.rsc 的果园教学：提前采果按钮和果实成熟度进度条均有说明。这不是把农田说明套到果园。
- Template/Orchard.rsc：独立果园采收按钮，绑定 OrchardComponent；食物资源上限。
- 苹果与梨的 FruitDescription 参数均为4个月、温度参数65及范围20；苹果原料低/高产量为50/65。

[玩家果园收获讨论](https://steamcommunity.com/app/242920/discussions/0/2961642818658956363/)描述每年只能采一次，采过的树即使再显示果实也不能再收。此项是玩家资料佐证，非官方引擎代码证明。工具包没有公开完整果实算法，不能据字段名称声称已经复现精确温度曲线、取整或再生显示。

## 本作的明确适配

仅新村启用。沿用48日/年，4个月折为16个适温生长日。每日将现有确定性摄氏气温换算华氏，生长因子为 max(0, 1 - abs(F - 65)/20)，进度每天增加该因子/16，封顶1。这个三角温度响应是本作适配，未经证实为原版公式。生长进度乘现有每树50基准向下取整，仅添加今天新增的整数果实；既有霜损不会被重新补齐。

采收前果实继续生长；秋季、长满或明确下达提前采果时由农夫逐树劳动，完成时仅取该株剩余实果。采过的树在当年不再生长或再收，不模拟原版玩家提及的不可再收视觉再生。本年最大50包含霜损，按钮不增加年度产量。保留现有4年有效养护成熟、寿命、教育影响工时、秋季霜损和入冬清果规则，本次不声称它们全是原版精确值。

本年指令在入冬或换年失效。清园优先并取消该指令；不允许在清园期间启动。旧任务仍受树对象、更新次数、岗位、年份和采收状态约束。食物目标挡住新派采收任务；已接受的劳动批次仍可完成，这是沿用的策略，并非硬截断每批产量。个人实际劳动与携货送仓继续沿用，不远程入库；中断和读档不追发果实。

## 保存边界

新村 v8 同时保留原气候/取暖/果园霜损规则，增加 orchardHarvestRules v1。逐树增加 fruitGrowth 和 harvested；可选 orchardHarvestYear 记录本年提前采果命令。读取严格校验版本、字段、范围、实果与生长进度关系、已采状态和合法命令。当天成长仍由原 orchardDay 和冷害日结守卫覆盖，加载不追算。

既有 v1–v7 不自动启用、不改变库存、现果或携货，保存仍保留原版本。v8 不可回退旧程序；旧读取器应拒绝版本，不能删字段冒充旧档。新规则的年度/日界、满仓与任务中断行为尚未实测。
