# 牛牧场、肉皮双产物与暖衣（0.3.33）

## 从贸易开始

商船增加牛，正常价800贸易单位/头，一次最多携带4头。购买2牛价值1600，可用229石（7/石，向上取整）支付。现有羊仍600/头。旧档当前停靠商船不凭空增货，牛从下一艘商船开始出现。

牲畜沿用原羊的交割合同：交易扣贸易站真实待售库存，购买的羊/牛分别进入全镇待安置数量，玩家再将同种牲畜放入牧场。牲畜不是仓库物资，不占贸易站2000件物资容量；当前没有牲畜从码头步行赶入牧场的动画。购买不是永久解锁，每笔购买都扣款且受商船余量和待售付款限制。

## 一场一种牲畜

空牧场选择羊或牛，应用后再放入已购牲畜。羊容量12不变，牛容量10，默认保留8；保留数可设2至本物种容量。牧场有牲畜、未剪羊毛、已屠宰待送产物、旧任务/挂起任务或来自该场的在途产物时不能切换，避免混养或将旧批次改成新物种。

至少2头同种牲畜且牧人近期实际照料才会繁殖，沿用原有增长节奏。牧人需要走到牧场劳动；无人照料后停长，不自动产肉。保持至少2头可继续繁殖，超过保留量才屠宰。

- 羊：沿用12头容量、羊毛增长与剪毛、24肉单趟屠宰产量，不出皮革。
- 牛：不出羊毛；一次超额屠宰产36肉＋4皮革。肉进入现有肉类，没有新增第四种饮食。
- 6×6固定牧场容量、繁殖速度与36/4产量均是本作适配，不声称Wiki原版密度或物理产量。

羊毛和皮革实际送仓后，可由裁缝按既有2羊毛＋2皮革配方制暖衣，补上从贸易牲畜到长期皮革来源的循环。

## 双产物守恒

一头牛只扣除一次，同时生成36肉和4皮革，记为本场已屠宰产物；一次最多拿20件，由牧人真实搬到可达仓库。正常需要20肉、16肉、4皮革三趟。不能把副产物直接加到全镇库存，也不会因为肉已交付再次扣牛。

任一屠宰产物达到生产目标或硬仓容时暂停新屠宰，牧人仍可照料。已经产生的物品不因后设目标而消失；优先送有仓位的品种，另一种仍留在原场。途中仓库被填满时只扣实际入库数量，余货带身保留，恢复仓位/通路后续送。羊的实际产物也沿用该有限保货路径，不重构其他普通食物物流。

牧场有已屠宰待送产物时不允许拆除，提示先搬空；已取走的货继续归原搬运居民，不随拆场消失。拆除将活牲畜按原物种退回待安置数量，牛不会变羊。未剪的羊毛仍属于活羊的生产进度，沿用旧拆场规则。

## 面板与存档

牧场面板显示已应用物种、数量/容量、保留数、各物种待安置数量、繁殖进度、待剪毛或待送肉/皮革、切换/屠宰暂停原因。选择控件与输入焦点原位刷新，未提交选择不会改变物种；旧面板、切村后的旧回调不能操作新场。

保存羊/牛待安置数量、牧场物种、繁殖/保留数、已屠宰产物及携货来源牧场ID。来源ID可指向已拆场，货仍保留。旧档缺少物种按羊恢复，羊数、12头容量、目标、繁殖与羊毛不漂移，牛库存默认为0。非法物种、超容量、牛羊毛或超过单次屠宰量的待送产物原子拒绝，不改当前村庄。
