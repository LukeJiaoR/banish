# 道路矿物清场

道路沿用现有起终点与鼠标拖动预览。石头、铁矿现在可以作为端点或经过格，不再作为规划硬障碍；水面、山体、建筑仍绕开。地图与悬停的可清矿格显示琥珀色（硬障碍仍红色）；预览分别显示树木、石头、铁矿数量，确认按钮或拖动松开一次性提交清场及铺路。

- 规划只读。确认捕获矿物坐标及种类；确认前新增矿物或石铁类型变化会拒绝旧操作，要求复查预览。
- 沿用普通散工 clearrock 实际采掘、工具影响、产量、仓容和实际送仓。没有免费删除矿石或直接赠送库存。此次不更改矿物碰撞：原版现有散工即走到资源格采掘。
- 路线未清场前不抢占散工为铺路工，不领取铺路石料；采掘完的货物继续按原搬运规则送仓，不能变成免费铺路材料。其他工人可在地面清空后施工，仍在途的矿物不会消失。
- 满仓的矿物继续留在地面等待。缺工、不可达仍按普通采集规则等待；无捷径越过水面或山体。
- 树木与矿物分别遵守现有 300 标记上限，任一超限整单拒绝，不创建部分标记或道路。
- 重叠道路复用已排工程及采集标记；暂停或取消道路保留独立清场命令。要停止采集，使用砍伐/采石采铁工具撤销相应标记；撤销后不会自行重新创建。
- 存档可保留待清矿道路，但清场未完的道路不能有已用材料、到场材料、在途施工材料或施工进度。非法地形/重复占格仍原子拒绝。
