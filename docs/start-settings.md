# 地图种子与无种子困难开局

版本0.3.68，跟踪 [Issue #73](https://github.com/LukeJiaoR/banish/issues/73)。在现有新游戏菜单中选择真实开局条件，不修改进行中的村庄难度。

## 原版依据与适配范围

[Map Seeds](https://banished-wiki.com/wiki/Map_Seeds)说明地图种子可由玩家设置、查看并用于重建相同地形。[难度说明](https://www.banished-wiki.com/wiki/Tutorials/Getting_Started_Guide#Difficulty_Levels)列简单六家庭、中等五家庭、困难四家庭；困难没有农作物/果树种子，须通过贸易获得。[Seeds](https://banished-wiki.com/wiki/Seeds)规定种子每种2500贸易价值，购买后永久解锁，而非每季消耗。

本片只开放以下两个已实现预设，默认选择保留现行开局。人口、物资与48日/年时钟属于本作适配，不声称精确还原三档难度。

| 开局项目 | 现行（适配中等） | 困难（无种子） |
| --- | --- | --- |
| 家庭 / 人口 | 5家庭，10成人+5儿童 | 4家庭，8成人+5儿童 |
| 木材 / 石料 / 铁 | 80 / 48 / 0 | 0 / 0 / 0 |
| 主食 / 总食物 | 500 / 500 | 400 / 400 |
| 柴火 / 工具 | 50 / 15 | 40 / 12 |
| 农作物与果树种子 | 仅小麦可种 | 全部未解锁 |
| 已建建筑 / 住房 | 起始储物车 / 无 | 起始储物车 / 无 |
| 牲畜、衣物及其他库存 | 均为0 | 均为0 |

[困难首年教程](https://www.banished-wiki.com/wiki/Tutorials/First_Year_on_Hard_Difficulty#Starting_Resources)列原版8成人5儿童、无木石铁，但有100柴、1200食物、20工具、20衣物。本作沿用既有工具/穿衣系统，不额外发原版20衣物，不隐式给已穿衣；工具仍默认共用池。库存、解锁与真实家庭数由同一预设数据同时驱动面板和开局，原有灾难默认关闭，开启真实家庭配送/个人工具等仍由各自已有入口决定。

## 操作与新局保护

1. 顶栏“新游戏”或游戏结束后的“再试一次”打开同一设置页。打开时暂停当前村，显示当前地图种子与已记录开局配置。旧存档没有配置时显示“未记录”，不根据当前资源猜难度。
2. 输入十进制整数种子，范围 -2147483648 至 4294967295，0有效；拒绝空白、指数、十六进制、小数和越界。随机按钮只改草稿，不消耗当前村的随机序列；“复用当前种子”填回现有数字。
3. 选择预设后先检查家庭、人口、物资、种子与风险，再进入独立最终确认。明确确认才放弃当前未保存进度、清理旧自动档并创建新村。手动档保持不变。仅打开、编辑、取消、失焦、隐藏页面、旧按钮迟到或生成失败不会清理存档。
4. “导出当前村庄”使用已有实际文件下载流程，操作后必须重新检查设置。界面只提示已请求下载，玩家仍应核对文件是否保存；不会把触发下载当作成功备份。
5. 返回、取消或Escape恢复原来的暂停状态；游戏结束的村返回结束页。键盘焦点留在前景窗口，重复Enter/空格、失焦后迟到点击、当前世界已更换、被其他窗口挡住时不能启动旧草稿。

创建阶段先在临时世界中完成真实地图生成、储物车放置、家庭建立与岗位初始化，成功后才整体替换旧村。出错时保持旧世界、游戏、随机序列和ID计数；设置页可继续修改。设置页可见时，定时、换季、页面隐藏/关闭等自动存档入口均暂缓，避免确认前改写旧自动档。

## 无种子的实际经营变化

困难开局不能靠默认小麦农田立即取粮。空田仍可显示小麦占位，但详情明确未解锁；派工、播种任务完成、成熟/早收判断和下一季选择均遵守种子资格。先标记采伐和露天采石取得建材，再建设采集、渔猎等食物来源，兼顾住房与冬季柴火；存粮只是建立这些来源的时间窗口。没有自动发建材、食物保底或首冬无敌。

小麦种子是独立贸易商品，标准价值2500，复用商人商品、订单与到港自动购买。付款从贸易站真实库存扣除，不能用面板总库存远程买种；同一种子只需购买一次，之后各田可重复种植。订货继续采用已有25%加价，非额外免费解锁。验证覆盖625柴换1份种子，以及3125订货价按每柴4价值向上整付782柴。购买后由真实农夫播种、收割并送仓，主食实际增量写入库存和账本。

## 存档与复现合同

保存 `startConfig:{v:1,preset,seed}` 及独立小麦解锁字段；开局配置仅是来源记录，载入时不会重新套用起始库存。旧档缺配置保留null，缺小麦字段按旧规则可种；不赠其他种子、资源、牲畜或衣服。带配置的新档必须保存明确布尔小麦解锁，防止删字段把困难改成免费小麦。种子与地图不一致、未知版本/预设、额外配置字段、未解锁却已播种的田等无效输入原子拒绝。

同种子、同预设、同版本生成相同初始地形、人口、库存和ID。正负32位别名可能生成同一地形；输入数字仍如实保存。现有存档没有保存中途随机位置与全部任务，故不承诺逐帧确定性回放，跨版本也不承诺地形永不改变。
