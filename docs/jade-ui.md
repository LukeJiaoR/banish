# 青玉轻界面：真实游戏布局候选

米白圆角面板、深青文字、青玉选中态。此版重组 HUD 和建造操作，不修改场景、建筑世界素材、生产链、资源数值、存档格式或建造规则。

## 布局

- 顶部常驻食物、木材、石头；铁、工具、柴火的原始资源节点移入“更多”，保留真实数量/标签/提示。已有隐藏资源告警计入可见徽标，现有取暖警告原文同步到“更多”。
- 日期、人口、无房提醒与暂停组成紧凑状态条。所有生存建议和引导保留在单行提示按钮展开的原面板内；紧急提示优先显示。
- 竖屏统一底部建造托盘：选中建筑大图、名字、实时成本/详情、取消，以及四列横向建筑图标。没有独立叠放的返回地图按钮和成本浮卡。
- 宽屏底部左侧为紧凑卡条，右侧为 180px 紧凑建造摘要。已建建筑保留详情管理面板。
- 建造卡片使用已有完整建筑 PNG；部分透明留白用 SVG viewBox 取景。农田缩略图组合已有作物素材，仅影响 UI。资源图标不变。
- 点按地图直接放置工地；没有假“确认建造”按钮。道路/采运等原有确认流程继续使用原控件。
- 成本详情对新工具默认收起，用户展开/收起的状态保留到后续实时刷新与旋转，不再被强制展开。

## 实现

- `styles/jade-skin.css`：颜色与表面；`styles/jade-layout.css`：新布局。
- `js/jade-layout.js`：移动既有节点而不复制事件控制，保留原工具、取消、收起与系统按钮；独立控制提示面板焦点与 Escape。
- `js/ui.js`：成本 disclosure 状态持久，以及可见资源集合/隐藏告警兼容。
- 暖色弹窗暂保留原样，并保留其高对比焦点。

## 验证边界

已通过真实浏览器查看桌面与同源 iframe 的 390×844、360×640、844×390 文档视口。重组版已检查 390×844 与 844×390；最终紧凑版继续核对 360×640 等视口。原生鼠标点击验证了建造分类、工具选择与暂停。iframe 自动滚动点击曾点错位置，以真实桌面坐标点击确认，未对应用增加错误的事件绕过。

这些是实际浏览器的文档视口和鼠标验证，不是真机触摸、设备 DPR、iOS Safari 或刘海安全区实机验收。浏览器不允许 DevTools 设备模拟，本次没有绕过限制。临时 iframe 检查页不纳入提交。

定向测试：
- jade-layout-ui：真实 UI/导航/布局脚本的七组最小 DOM 行为测试；覆盖移动控件、建造/暂停/取消/收起、分类返回、焦点、单层 Escape、弹窗保护和资源节点唯一性。
- jade-resources-ui：移入更多后的铁告警计数、取暖紧急徽标、原文提示和工具实际数量。
- jade-skin-ui、mobile-occlusion、placement-ux、navigation-ui、build-affordance-ui、color-icons-ui、category-cards-ui、details-readability-ui。

## 图标与文字的取舍

用户希望减少重复文字和 UI 占比。本版建筑卡片只显示图标，选中名称和成本只在摘要行显示；分类、取消、告警和展开详情继续保留文字。所有建筑卡片在隐藏视觉文字前设置显式 aria-label，保持原 tooltip。单次选择即可看到名称，不依赖悬停或长按。

参考的是具体场景，不是“所有游戏都只用图标”：
- [Banished 官方模组文档](https://shiningrocksoftware.com/game/mods/) 展示建筑/职业图标按钮与 tooltip。
- [Pocket City 2 官方建造截图](https://pocketcitygame.com/pc2assets/1_build.jpg) 使用资源图标加数量，也保留 Build 文字入口；[统计截图](https://pocketcitygame.com/pc2assets/6_stats.jpg) 对展开指标保留名称。
- [Township 官方工厂帮助](https://playrix.helpshift.com/hc/en/3-township/faq/10055-how-do-i-find-and-unlock-factories/) 将所选工厂条件作为选择后的信息。
