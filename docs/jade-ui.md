# 青玉轻界面：真实游戏布局候选

米白圆角面板、深青文字、青玉选中态。此版重组 HUD 和建造操作，不修改场景素材、生产链、资源数值或存档格式。普通单栋建筑改为真实“选址 → 确认工地”，底层选址、施工和领料规则沿用原实现。

## 布局

- 顶部常驻食物、木材、石头；铁、工具、柴火的原始资源节点移入“更多”，保留真实数量/标签/提示。已有隐藏资源告警计入可见徽标，现有取暖警告原文同步到“更多”。
- 人口图标/数量、暂停与资源告警徽标常驻；宽屏日期常驻，窄屏日期、住房与健康移到更多明细。无房状态在窄屏人口旁保留小提示点。所有生存建议和引导保留在单行提示按钮展开的原面板内；紧急提示优先显示。
- 竖屏统一底部建造托盘：选中名字、用途、可见图标成本，独立的取消/确认操作行，以及四列横向建筑图标。标题可展开完整用途与返回分类入口。没有独立叠放的返回地图按钮和成本浮卡。
- 宽屏底部左侧为紧凑卡条，右侧为 176px 建筑图、名字、用途、成本与操作摘要；长详情展开为左侧弹层。已建建筑保留详情管理面板。
- 建造卡片使用已有完整建筑 PNG；部分透明留白用 SVG viewBox 取景。农田缩略图组合已有作物素材，仅影响 UI。顶部和成本采用一致的原创描边谷物、原木、石块图标；数量和资源语义不变。
- 普通单栋建筑点按地图只记录待确认位置，使用真实建筑素材以65%透明度加入原深度排序预览，不创建模拟建筑对象；确认后才调用原工地放置逻辑。确认前重新检查地形、占用和材料，重复/过期/被打断的激活不会误放。农田、牧场、果园、墓园、道路与采运的原有规划流程保持不变。建造材料仍由工人之后实际领取，不在确认时预扣或预留。
- 无效选址的原因直接替换用途行显示；完整建筑说明不依赖悬停位置。展开详情、资源更多和引导均可单层 Escape 关闭。
- 使用随仓库分发的 Noto Serif CJK SC 字体子集（常规/粗体 WOFF），许可见 assets/fonts/LICENSE-Noto.txt。面板为暖象牙纸色，标题深青，主要按钮为青玉渐变。

## 实现

- `styles/jade-skin.css`：颜色与表面；`styles/jade-layout.css`：新布局。
- `js/jade-layout.js`：移动既有节点而不复制事件控制，保留原工具、取消、收起与系统按钮；独立控制提示面板焦点与 Escape。
- `js/ui.js`：成本 disclosure 状态持久，以及可见资源集合/隐藏告警兼容。
- 暖色弹窗暂保留原样，并保留其高对比焦点。

## 验证边界

已通过真实浏览器查看桌面与同源 iframe 的 390×844、360×640、844×390 文档视口。后续参考图对齐版独立检查字体、表面、布局、图标尺度及成本/操作层级；实际点击验证有效/无效选址、确认创建工地与详情展开。原生鼠标点击验证了建造分类、工具选择与暂停。iframe 自动滚动点击曾点错位置，以真实桌面坐标点击确认，未对应用增加错误的事件绕过。

这些是实际浏览器的文档视口和鼠标验证，不是真机触摸、设备 DPR、iOS Safari 或刘海安全区实机验收。浏览器不允许 DevTools 设备模拟，本次没有绕过限制。临时 iframe 检查页不纳入提交。

## 图标与文字的取舍

用户希望减少重复文字和 UI 占比。本版建筑卡片只显示图标，选中名称和成本只在摘要行显示；分类、取消、告警和展开详情继续保留文字。所有建筑卡片在隐藏视觉文字前设置显式 aria-label，保持原 tooltip。单次选择即可看到名称，不依赖悬停或长按。

参考的是具体场景，不是“所有游戏都只用图标”：
- [Banished 官方模组文档](https://shiningrocksoftware.com/game/mods/) 展示建筑/职业图标按钮与 tooltip。
- [Pocket City 2 官方建造截图](https://pocketcitygame.com/pc2assets/1_build.jpg) 使用资源图标加数量，也保留 Build 文字入口；[统计截图](https://pocketcitygame.com/pc2assets/6_stats.jpg) 对展开指标保留名称。
- [Township 官方工厂帮助](https://playrix.helpshift.com/hc/en/3-township/faq/10055-how-do-i-find-and-unlock-factories/) 将所选工厂条件作为选择后的信息。
