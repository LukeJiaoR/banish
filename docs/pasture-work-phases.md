# 牧场：已产物取货不再重复整轮照料劳动

2026-10-20，基于 `f9e22702652b2c7ecf34ac0019e0ffdbe8d919dd`。接续 [满容量繁殖修正](pasture-capacity-birth.md)，只拆开**已经存在的产物取货**与**真正的照料、剪毛、屠宰**。保留选定界面、固定地块、旧面积场，以及所有容量、单次产量、繁殖速度、死亡和食物消耗参数。

**本文保留本片完成时的历史结果：远仓鸡场零肉的问题当时仍存在。后续独立的[照料优先级修正](pasture-care-priority.md)处理了新蛋抢占，并记录减少鸡蛋的运输权衡。本片本身只修重复取货工时，不代表农业整体平衡。**

## 证据与范围

原羊场的8小时任务同时负责照料、剪毛或屠宰。提交 `52039f9` 引入牛的36肉＋4皮革和三趟运输时，把剩余16肉、4皮革的取货接进了同一个任务，却保留每趟8小时。提交 `1f30d41` 又把鸡蛋放入相同取货路径。于是只搬运已经生产完成的货物，也要重新支付整轮劳动。

[原鸡场规则](chickens.md)将8小时明确用于照料，并允许饥饿牧人拾取已产鸡蛋且不续照料日。[官方工具包](https://shiningrocksoftware.com/game/mods/)的 `resource/Game/Help/Pasture.rsc` 和 `resource/Template/Pasture.rsc` 也将牧人生产与产物运仓/拾取分别描述；它们没有提供可直接套进本作时间比例的“取货工时”。本次0.1小时来自本作铁匠、伐木、裁缝、酿酒取料阶段已有的实物搬取约定，**不是声称原版牧场只需0.1小时**。

相同48日满场实验，原调度记录到：

- 牛近/远仓各有8个任务在接单时就已有成品等取，仍各支付8小时，即64个基础工作小时。
- 远仓鸡场共完成48次8小时任务：1次纯照料，47次带走已产蛋。其中45次在接单时就有鸡蛋等取，共360个基础工作小时。全部任务有效工作进度合计384小时。
- 近仓鸡的47次取蛋都发生在已经开始的照料任务结束时。它们不是“接单时已有成品”的重复取货，不能一律削成短任务。

因此只对接单时已有可取成品的任务分流。不会把8小时任务中途变短，也不会为了得到更好看的肉量跳过待送产物门槛。

## 修改后的契约

- 有可取的已产肉、皮革、鸡蛋：派发基础0.1小时的取货任务，锁定一种产物；到真实工作点后最多拿20单位，继续实际走到仓库。
- 取货不写照料日，不推进繁殖，不剪毛，不屠宰，不记录第二次生产。羊毛仍需完整剪毛工作；羊原有一次24肉的屠宰随身批次不变。
- 没有可取成品：仍是原8小时照料/剪毛/屠宰任务，教育、健康、幸福度和工具的既有处理不变。短取货沿用牧场已有健康/工具进度处理，并未将工具规则另行放宽。
- 接单后货被别人取走或仓库变满，只能空手结束；不能升级成免费照料或改拿另一种货。两个工人按完成顺序扣真实余量，完成的任务不能重复结算。
- 生产目标只阻止新生产，不能没收旧产物；满仓、部分交货、断路、在途货继续走原有保留/恢复链。
- 撤岗时当前已接批次按原规则送完后释放，不继续取下一批。夜间暂停保留当前剩余工作；旧任务无阶段字段仍按完整照料结算。
- 存档格式没有变化。和现行版本一样，读档会重建未保存的任务；待送货、在途货、活畜和繁殖小数按原值保存，不借读档补产或重放。

## 满场实际收货与工作量

使用 `tests/fixed-pasture-balance.js` 原模拟，种子5、两名30岁成年男性、1名牧人，无生育配对。房屋(9,14)、固定6×6牧场(13,8)，近仓(8,8)、远仓(26,8)，另有远处备用仓共8座。预置300粮、1000柴和1000工具，从第0日6时连续运行48日。这是**有补给的生产实验，不是从零生存或购买回本实验**。

| 12羊，近仓 | 120肉＋47毛 | 120肉＋47毛 | 596.05→596.05 |

这里的“有效工作进度”是实际任务 `workLeft` 消耗总量，包含截止时未完成任务；不是扣除健康/工具等速度因素后的精确钟表工时。JSON同时提供按阶段的有效进度和每0.1小时的工作/行走状态采样。所有种类都有真实生产、deposit接受量、received事件、场内/在途余货、弃货守恒断言。

牛的总在岗工作不一定下降：提前搬完之后，牧人继续开始新的完整照料任务，并没有被改成休闲或空闲。不能把所有照料都看成重复劳动。

另跑种子5/49、初始8头/只且保留8的近远仓12组，修改前后实际收货与末尾畜数全部相同：羊72肉＋31毛、牛108肉＋12皮；鸡近仓42肉＋194蛋、远仓0肉＋300蛋。无工人三物种对照均无出生、屠宰或产出。没有只挑鸡场或只看满容量的一组结果。

### 远仓鸡为什么仍没有肉

原始时间线：第0日15.4时完成首次照料；第2日14.6时完成下一轮劳动时，满场繁殖进度已到1，但当天12枚蛋正在场内，于是先取蛋。第3日7.7时再接任务时已有12枚新蛋，原代码又用8小时做取货，到19.5时才拿走。此后每日同样被产蛋和往返占据，出生进度一直保留为1。

改后第3日相同任务只做短取货，11.6时拿蛋，15.8时实送入库；随后的完整照料仍需8小时加返程，跨到第4日12.4时才结束，而第4日的蛋已产生。现行“场内待送产物先搬空”规则仍让它先取蛋。

两组都实产576蛋、实收564蛋，末尾12蛋在场；没有把蛋凭空变成肉。远仓仍有显著实际行走和送货成本。解除这一优先级门槛或为屠宰保存跨趟工作，需要单独评估玩法、存档及库存边界，未混进本片。
