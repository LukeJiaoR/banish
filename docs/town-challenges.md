# 市政厅发展挑战（0.3.49）

市政厅现有详情中增加一个折叠区，帮助玩家从保住开局走向稳定村庄。它补充既有的四步开局指引和库存生产上限，不取代实际生产、住房、教育或贸易机制。无需另建建筑、安排职员或领取奖励。

## 三项独立条件

- **安居村庄**：至少30名已经入村、仍存活的居民，且每人所属家庭都有完工木屋、石屋或宿舍。迁入途中者不计；工地、空屋数量不算已安置。记录住房分配，不声称每人此刻正在家中。
- **一季多元生产**：紧接今天之前的连续12个完整记账日，肉、蔬菜、主食三类都曾有真实产出；三类合计产出不少于实际居民食用，且实际食用大于0。首日部分记录、缺日、只进口食物或只有库存都不能替代。产出可仍在搬运，不等于入库；这也不保证均衡饮食、库存充足或下季继续自给。
- **教育传承**：至少3名已受教育的成人，另有至少1名已开始积累课时、仍在读且所属学堂完工的学生。没有课时的注册不算，永久退学者不算；此项不是对所有人受教、连续多年教学或老师此刻在场的证明。

三项可分别达成，没有资源奖励、效率加成或额外解锁。面板显示当前数量和缺口；已达成后即使后来人口、供给或教育倒退，记录仍保留，当前数据仍更新。

## 日期和存档

日界在本轮人口、消费与教育处理之后观察一次，首次满足才记录当前游戏日（沿用市政厅现有第0天起的日期）。建市政厅前也观察已有村庄，建成后可查看；打开或刷新详情本身不授予记录、不修改资源。

旧档没有挑战记录时从空记录开始，不从人口历史或旧库存推算过去。首次看到满足条件时，只记本次观察日，不称历史首次完成日。载入本身不立刻评奖，下次正常日界观察；缺少完整12日流水时不能提前完成食物挑战。

存档只增加版本号与三个可选日期，拒绝未来日期、非整数、未知键和损坏结构，校验失败不替换当前世界。已有记录在多次保存/载入后不重复授予或改写日期。

沿用已有换季自动保存发生于日界中途的时序：该快照先于本轮日终观察，所以刚在该日界首次确认的结果可能尚未写进这份自动档。载回它后不会伪造已经观察过的结果，之后正常日界重新观察并记录当时日期。手动保存会保留当前已经确认的日期；本片未重构全局自动保存时序。

## 验证范围

核心检查覆盖空村、真实家庭住房、迁入途中排除、完整/部分/缺日流水、进口不算自产、三类产出、教育状态、真实日界首次观察、反复载入与非法记录拒绝。市政厅和流水DOM检查覆盖实时缺口、日期、旧世界切换、刷新焦点保持、缺少流水API时明确未知而非伪造零产出。

迁入旧档测试原本把第0日存档日期直接改成100、却保留第0日账本，当前发布基线也会因流水日期缺失拒绝；本片只让该旧档fixture同时缺省流水，以正确测试旧档迁入宽限，没有放宽实际存档校验。

无新图或渲染改动；DOM/stub验证不代表真实浏览器或手机试玩。聚焦回归不声称历史无关失败全部消失。
