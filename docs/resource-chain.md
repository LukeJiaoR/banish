# 石、铁、煤与工具链（0.3.26）

## 实际玩法

工业菜单新增独立采石场（3×3、2名石匠、64木32石）：基础9小时产6石。矿井仍为2名矿工，新增矿井默认专采铁，可在详情切换煤；基础9小时产6铁或8煤。新资源要从真实工作入口搬到可达仓库才入库，满仓余矿由工人保留，腾出空间后继续送仓。专采模式只检查自身产物的库存、全镇目标和仓容。

铁匠铺可选择两种配方：
- 铁工具：1铁＋2木，产2件；受教育工人产3件。
- 钢工具：1铁＋2木＋2煤，产量相同。

自0.3.43起，铁匠在实际抵达堆料场/仓库时整批扣除并携带原料，回屋加工时消耗这批随身材料，不再次扣公共库存；中断或读档原料退仓。详见 [铁匠物流](blacksmith-input.md)。缺煤等原料时停工并提示。切换矿种或配方只影响新接批次；已接批次仍按原产物/原配方完成，工人已有货物先送仓。工人可以先采煤，再切回铁，或建设两座分别供应的矿井。

工具继续采用当前原型的全镇工具池：铁工具提供120成人天，钢工具240成人天。每天先磨损钢工具，剩余劳动需求再磨损铁工具，不重复扣两种库存。钢与铁生产效率相同；任一种有货即可避免无工具减产。HUD悬停同时显示两种库存和扣除部分磨损后的合计天数。

铁、钢工具分别有全镇生产目标。铁匠的本屋目标默认30，只作用于当前选择的工具种类，并与该种全镇目标取较低值；达到后暂停新批次，已接批次仍可能使库存超目标。工具不限仓容。煤与钢工具可以作为贸易站待售品，也能向商人换购，单价分别为6、10贸易值。

## 旧档与当前适配

- 旧档没有矿井模式时，迁移为可见的“旧档石铁混采”：沿用四批石、一批铁及满仓回退规则，不突然丢失石头来源。仅玩家主动切换后改变；旧矿井也可切回混采。新井不能选择混采。
- 旧铁匠默认铁配方；缺少煤、钢工具、钢工具磨损字段时补0。新存档保存矿种、旧井标记、混采计数、配方和磨损。非法枚举、负库存或非法钢磨损会拒绝导入，保留当前城镇。
- 本批矿井和采石场明确显示无限矿源，可正常拆除。未引入枯竭、永久废坑、矿难或煤供暖；住房仍仅用柴，避免无提示改变已有过冬预算。
- 原版是个人工具与更大采掘建筑，本作保留已有工具池、自动派工、小地图成本和既有铁配方数值。三类食物合同不变。

## 原版依据

[Mine](https://banished-wiki.com/wiki/Mine) 的铁/煤择一开采、[Quarry](https://banished-wiki.com/wiki/Quarry) 的独立石料供应构成资源分工依据；原版有限矿藏和不可恢复矿坑暂不移植。

[Tools](https://banished-wiki.com/wiki/Tools) 指出钢工具的寿命为铁工具两倍，效率相同；[Blacksmith](https://banished-wiki.com/wiki/Blacksmith_(Building)) 的铁、木及加煤制钢关系用于本作配方。这里没有按原版1木产量覆写旧铁匠数值。[Coal](https://banished-wiki.com/wiki/Coal) 作为钢工具原料与贸易品，煤供暖留待燃料选择独立实现。
