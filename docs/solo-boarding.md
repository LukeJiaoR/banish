# 0.3.7 单人家庭入住宿舍回归

基线：`7f9c41f`。无房的单人家庭已能分到独栋住宅，但宿舍兜底只遍历两人以上家庭，导致独居成人、父母去世后的独生孩子或丧偶者在宿舍空着时仍无家可归。

修复仅让宿舍兜底依次遍历多人户和单人户，与独栋分房使用相同的无房家庭范围。每栋仍限五家；先分空木屋/石屋，无房户优先于已有宿舍的住户，空独栋出现后宿舍住户照常搬出。未完工宿舍、空家庭和没有家庭记录的市民不新增入住资格；婚配、生育、经济数值与存档格式均未修改。

- 新增 `tests/boarding-regressions.js`：基线 3 通过 / 8 失败；修复后 11 通过 / 0 失败。
