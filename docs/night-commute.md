# 夜间绕路与未完成工作（0.3.20）

## 复现与原因

专业屋人效实验中，seed74的伐木工在工作点(63,52)、家(60,47)之间循环：距房屋中心直线4.47格，绕建筑/地形后的回家路线18.83格。22点返家、次日再出发，剩余3小时加工连续多晚不减少。旧露宿判断只看直线10格阈值，未识别这个实际长通勤。

这不是丢失任务进度，也不是没有原木。用既有道路规划功能、先由工人清掉一棵树再铺21格路，可以在该实验中解决交通瓶颈。该例包含尚未发布的人效参数，不能把它的城市结果当作0.3.20基础数值验收。

## 最小修复

- 保留原有直线超过10格、无房或没有回家路径时就地休息的规则。
- 对有暂停工作且已经找到回家路径的市民，累计该路径实际长度；若超过同一10格阈值，就地休息，天亮继续原任务。
- 使用已存在的路径，从当前实际坐标累计；不新增A*、不每帧重算、不缓存跨日/跨地图结果。
- 没有暂停工作的普通回家行为保持原样。夜间工作仍停止，室外休息仍按原寒冷规则受冻。道路、近岗住房及仓库依然影响交通效率。
- 不移动人物位置，不补工时、不生成资源，不丢背货，不改变生产/移动/死亡常数或存档格式。

## 验证

`node tests/night-commute-distance.js`覆盖7组：近直线长绕路、次日真实工时推进、普通短路、刚好阈值、远处旧快捷分支、无工作普通回家、找不到路/住房消失、空路径已到家。断言长绕路复用现有一次路径查询，任务与货物保留。

另运行完整既有回归与固定40局5年矩阵；发布说明记录最终提交的实际结果。所有验证为Node模拟与代码契约，未完成真实手机/浏览器试玩。
