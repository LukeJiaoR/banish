# 衣料选择与裁缝运输（0.3.47）

[Banished Wiki: Tailor (Building)](https://banished-wiki.com/wiki/Tailor_(Building)) 将皮革、羊毛和混合暖衣列为不同配方，受教育裁缝用相同原料产出更多衣物。本作保留普通衣/暖衣两类库存和既有冷损/耐久规则，通过原料选择提供生产取舍，不再增加等价衣物种类。

## 玩法

普通衣可选「自动：优先皮革」「仅皮革：保留羊毛」「仅羊毛：保留皮革」。自动保留旧规则，皮革不足2时用羊毛；明确限定后若该材料不足，就暂停新批次并说明原因，不擅自改用另一种。暖衣始终同时需2皮革＋2羊毛，普通衣选项在暖衣模式下不可操作，但偏好保留到切回普通衣。

接受任务时锁定用料和产物；之后改选只影响新任务，不能把已接普通衣变成暖衣，或把已取皮革变成羊毛。裁缝实际走到通用仓，确认整批原料和回铺通路后原子领取；混合暖衣要么同时取齐两种，要么完全不取。此时公共库存减少，已经领取的材料不能又被贸易或其他裁缝花掉。露天堆料场不接皮毛，不能作为衣料仓。

工人携带同一批衣料，实际回到裁缝入口后制作。基础8游戏小时、1名裁缝，未受教育产1件/受教育产2件，工时教育加成沿用已有规则；完成只把随身原料替换为成衣，不再次扣库存。衣物送仓后才可由居民领取。面板区分库存、新批次用料、原配料是否已出库、携料/制作/夜间暂停、未用衣料退仓与在途衣物；居民状态可看实际携料。工时和时间尺度为本作适配，并非原版精准用时。

## 中断与旧档

降0工或关闭生产目标按原有限批次收尾；夜间保留当前原料与剩余任务，次日实际走回。被新建筑挤离或封路不能在原地隔空加工；回铺不可达则退原料，退仓也不可达就保货节流重寻。分两种原料逐次退仓时，即使第一种仅有部分仓位、退完后主货换成第二种，保护仍跟随本批，不能误成一批新衣物。

保存已领取的实际材料、普通衣原料偏好与成衣在途数量，不保存任务/剩余工时。读档后未用原料先安全退仓；已经完成的成衣继续送仓，不重复扣材料或赠送未完成成衣。原料及成衣满仓余量沿既有保货通道等待；拆铺不吞掉现货。旧档没有原料选项时默认自动，原库存、已穿衣物和剩余耐久不改。旧空手任务本来没有扣材料，也无需追溯制造随身皮毛。非法选项、超量或混杂货批原子拒绝载入。

仍为公共库存和实际路线模型，未增加地方库存、成衣自动换新或死亡掉落。居民死亡沿既有背货处理。普通衣与暖衣仍分别降低户外寒冷40%/70%，住房柴火依赖不变。
