# 两种果树与实际果品酿酒

版本0.3.66，跟踪 [Issue #69](https://github.com/LukeJiaoR/banish/issues/69)。复用既有逐树果园、仓储家庭补给和酒馆取料，不扩生产平台。

## 原版依据与适配

- [Orchard](https://banished-wiki.com/wiki/Orchard)：苹果、梨等果树从种子种植，约4年成熟；更换选择影响随后新种/补种，不直接改现存树。
- [Seeds](https://banished-wiki.com/wiki/Seeds)：种子2500价值，买一次永久解锁，非消耗品。
- [Tavern](https://banished-wiki.com/wiki/Tavern) 与 [Ale](https://banished-wiki.com/wiki/Ale)：苹果/梨可作酒原料，每30果品产10酒；原版小麦100产10。
- [Pear](https://banished-wiki.com/wiki/Pear)：可食/可酿，交易价值1。苹果按同类基础食物价值1为本作明确适配；本次Apple单页读取超时，不据此臆称该页核实。

原主食30→未教育3/受教育4酒的本作合同保持；苹果与梨每批30→10，教育不再额外增加此批产量。工时6小时、固定6×6/9株、每树20产物、12–20年错峰寿命与现有48日年都是既有小地图适配。酒的产出仍汇入同一 `ale` 酒库存供既有休闲消费，不新增三种酒品或营养来源。

## 玩法链

1. 贸易买苹果/梨种子各一次，分别永久解锁；果品也能作为独立货品交易。已有在港商船不补塞新品，随后到港/订单/自动购买继续各自规则。
2. 在果园显式选择以后的种植品种。选择只改变以后新接的种植任务；已接任务、现存成熟树、树龄、周期和当前果实保持原品种。自然枯死空位再按新选择补种，可逐渐形成混种果园。
3. 农夫实际到树边种植和养护，达到既有成熟条件后秋季采对应果品，实背送仓。苹果、梨、旧通用树的蔬菜分别记账，满仓与在途保全。
4. 公共供给或已启用的市场/家庭补给都按真实物品搬运与消费。六食物物品仍是三营养组：肉/蛋白（肉、蛋），蔬菜（蔬菜、苹果、梨），主食。水果独立不是额外幸福/健康加成。
5. 酒馆选择下一批主食、苹果或梨。工人到可达通用仓实际领取整批、背回、加工、再送酒；口粮保留、健康、工位、路径和目标仍生效。苹果不足不会暗取蔬菜、梨或主食冒充。
6. 已接/在途配方拥有自己的品种、数量和产量；中途改变下一批选择不让原料漂移。中断或重载的实货按原物品退仓，满仓继续保留，不能凭公共计数隔空加工。

## 旧档合同

- 旧通用种子解锁保持；不会免费解锁苹果或梨。
- 旧树的年龄、果实、周期和照料记录保留，缺品种字段时记为 `legacy`，继续产蔬菜。已有蔬菜无来源明细，不转换成苹果/梨，也不能作为果品配方原料。
- 旧树图本身是红果外观，继续复用；新苹果也使用它，但两者资源合同在果园详情中分开。梨树有独立带果/采空图。
- 新果品的公共库存、家庭库存、流水缺项补零；原食物总量、鸡蛋、供给模式和其他货物不变。原先支持的旧库存形状继续接收。
- 旧酒馆缺配方字段默认主食，旧30主食携料保全。错误品种、未解锁选择、非法库存/批量或食物合计在替换世界之前拒绝。

## 美术与验证

[素材、完整提示词和原图SHA](art-assets/fruit-orchards.md)。复用原苹果/旧通用树与幼树叶图，新增梨两状态、苹果/梨篮；52px成熟树、24px幼树、20px货品与旧素材并排检查。

定向验证覆盖果品真实生产与家庭/贸易/酿酒、补种和在途合同、旧档守恒、焦点/旧页面/重复键盘操作、资源清单和按树品种绘制。受影响回归围绕果园、酒馆、鸡蛋营养与补给迁移，不扩CI或全套随机地图矩阵。结果属于模拟、DOM和离线绘图/素材检查，未进行真实浏览器或手机视觉验收。
