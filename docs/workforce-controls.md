# 建筑用工上限与施工暂停（0.3.34）

> 0.3.71 起的新工地使用 [建材实运](construction-delivery.md)：放置不预扣/预留库存，到仓领取才扣，齐料到场后施工；已付旧工地保留原进度和退款合同。本文历史付款说明以该增量为准。

## 在原建筑详情分配劳力

每座已完成的生产或服务建筑，可以把用工上限设为 0 至原本最大岗位数之间的整数。填好后点击「应用用工上限」才生效；没有提交的输入在信息刷新时保留。住房、仓库、市政厅等无岗位建筑不提供无意义的输入，但仍能展开只读的全镇人力概览。

上限是允许自动调度使用的最多人数，不是预留或保证配足的人数。仍沿用现有低占工、单工效率和粮食/施工/季节调度；缺人、原料不足、满仓、工作不可达或没有当前任务都可能让实际人数低于上限。食物和柴火岗位降额可能导致断供，缺粮救急也不会越过玩家设定。

面板显示实际占岗、其中收尾、已应用上限、原最大人数及当前原因。全镇成人劳力排除学生和尚未入村的移民；已分配中的收尾人数是子集，不能相加当成新人口。可再派工人数不包含携货、收尾或正接受个人服务的人；无岗带货单列。每人始终只有一个岗位，不会因为多座建筑都缺人而被复制分配。

## 降额与已接批次

降上限先释放空闲者。已经接下的有限工作，包括途中原料、加工、采集或生产后的送仓，保留本批并在结清后撤岗，不再开始下一批。实际占岗因收尾可暂时超过新上限。降低后又恢复上限，会撤销尚未完成的撤岗请求；不重做或复制已有批次。

教师、诊所医师和酒馆接待这类持续服务不能无限期“做完本批”：停用后立即停止服务并释放正常服务人员。学堂学生保留已学课时，并尝试转至可达且有教师空座的学堂；无处可去时保留学籍。患者保留病程和已治疗进度，可继续寻找其他医疗点。草药屋 0 人也停止保健服务。正在酿酒的有限加工批次则照常结清，接待服务先停止。

主动撤岗时，当前已携带的货物及该有限批次随后产生的货物带有专属保全标记。满仓仅交付实际可入库量，剩余货由同一居民保留；狩猎肉和皮革等副产物分开继续送仓。继续占原岗位的收尾者不算空闲，跨夜休息、每日吃饭和未装满的田间批次也不提前腾出岗位；界面显示仓满或路线阻断原因；使用库存、建成仓库或恢复路径后再搬运。暂停工地立即释放岗位，已携货的原建筑工仍先送仓，计为无岗带货，当前保全货物未卸净前不能分配至其他建筑。

标记绑定当前随身货批与剩余数量，不是居民的永久能力。全部卸货后当前货物对象清除；之后正常采集的新批次不会继承。反复调 0、恢复或暂停不会再次产出或多次生成副产物。本片只保障主动撤岗/暂停涉及的当前货物，未声称解决所有普通资源原有的满仓丢弃余量问题。

## 暂停施工

未完成建筑和木桥显示各自固定的「暂停工地」「恢复工地」按钮，只有适用的一个可操作。暂停立即停止派工、取消当前未完成的小工段并释放建筑工，已完成工段、已砍树和已付建材不回退；未砍完的树仍在原处。恢复后重新调度，未完成小工段从头做，建材不会再次扣除。取消工地/拆除仍使用已有退款规则。

暂停只改变施工状态，不修改地形、道路、导航连通或桥梁碰撞。未完工桥原本不可通行，暂停后仍不可通行；已完工桥不提供暂停按钮，也不会因本操作封掉既有道路或桥梁。

旧页面、旧村庄和读档前的按钮回调不能作用于新实体；暂停按钮固定为“暂停”意图，重复点击不会变成恢复。工地完工后旧暂停回调不能再停用成品。

## 保存与旧档

存档保存建筑上限、工地暂停和当前携货的保全标记/数量/副产物。旧档缺少字段时沿用原自动上限与施工状态，不默认关停建筑。非法上限、暂停字段或保全标记在候选档校验阶段原子拒绝，不改当前村庄。

本游戏原有存档不保存正在执行的完整任务对象；读档继续沿用此合同。已产出的实际携货及已扣取的随身原料保留，按存储的上限重建岗位；超出上限者撤岗、先送回现货，不凭空兑现未完成任务。收尾者读档后可能从“原岗位收尾”变成“无岗带货”，总货量和不能空手重派的约束不变。

## Wiki 依据与本作适配

[Citizen](https://banished-wiki.com/wiki/Citizen) 的职业分配、[Builder](https://banished-wiki.com/wiki/Builder) 的暂停工地和 [Laborers](https://banished-wiki.com/wiki/Laborers) 的散工职责是参考。原版以全局职业数量为核心；本作保留已有自动调度，仅加各建筑上限和施工暂停，不重写职业系统。建材沿用本作放置时扣款，因此暂停恢复保留已付材料，不宣称原版逐件建材配送。

## 验证与限制

定向测试覆盖岗位总量、0 人和有限批次撤岗、满仓仍占岗、狩猎多产物跨读档守恒、恢复上限后新货不继承标记、原粮酿酒结清、教师/医师真实停服、施工跨夜续接、暂停/恢复不重扣料、旧回调、木桥通行和旧档默认。DOM 测试包含整数输入、焦点和未提交值、重复点击、换村/加载同 ID 新实体、完工后旧回调以及各专用建筑详情刷新。

没有新增建筑或动物美术，沿用已有素材和面板色彩。离线模拟及 DOM 验证不代表真实浏览器/手机试玩；此前浏览器启动受当前环境 socket 限制，本片不重复将它当作已通过的检查。无生产部署。
