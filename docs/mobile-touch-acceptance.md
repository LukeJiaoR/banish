## 修复的缺陷

### 1. 阻断：手机端画布被撑成 2 倍，世界只剩四分之一可见

`js/main.js` 的 `resize()` 先写画布位图尺寸（`innerWidth * dpr`），再写 CSS 尺寸。手机上（DPR>1 + shrink-to-fit）位图写入的瞬间画布变成 dpr 倍宽，Chrome 把布局视口撑到该宽度并写回 `innerWidth`，随后代码把放大后的值写进 CSS，形成不可自愈的 2 倍画布。

实测（390×844 @DPR3）：`innerWidth` 变成 **780**，画布 CSS **780×1688**，`documentElement.scrollWidth` 780；顶栏与底部操作条按 390 排版，画布却按 780 绘制 → 只显示世界左上角，镇子落在屏幕外。

最小复现确认开关就是赋值顺序：

| 赋值顺序 | innerWidth | 画布 CSS 宽 |
|---|---|---|
| 位图 → CSS（原实现） | 780 | 780px |
| CSS → 位图 | 390 | 390px |

改为先定 CSS、再定位图，并加注释说明原因。修复后四台设备的 `innerWidth`、画布 CSS 尺寸与设备宽度完全一致（390/375/360/844），回归断言「画布/视口未被放大」常驻脚本。

### 2. 手机无法平移地图

`main.js` 只在鼠标左键拖动（无工具、位移 >4px）与 WASD 时改 `G.cam`，触摸侧没有任何平移入口。竖屏 390×844 上可点地图只有 13–20%（工具态）到 32–52%（探索态），等于只能看开局那一屏。

新增单指平移，门槛与鼠标一致：无工具、无农田/牧场/果园/墓园规划、无弹窗、单指、累计位移 >6px。位移 ≤6px 不拦截默认行为，选址仍走兼容鼠标事件；超过门槛后 `preventDefault()`，同时抑制这次点按造成的误选。`resetInput()` 一并清理手势状态。

回归断言：拖拽后 `G.cam` 变化（三台竖屏均 PASS），且拖拽结束不弹出建筑详情（「拖拽不误触选中」PASS）；桌面鼠标拖动平移与点击建造冒烟同样通过。

### 3. 两个触控目标小于 44px

- `#guide-toggle`（生存清单「全部」）在小屏被压到 **53×36**
- 动态引导的「为什么？」`<summary>` 为 **326×30**

分别改为 44px 高（`styles/navigation.css`、`styles/onboarding.css`），与其他 44px 控件一致。修复后 8 个可点元素全部 ≥40×40。

## 通过项（每台竖屏 21 项）

无横向溢出；画布/视口未被放大；顶栏与底部操作条在视口内；触控目标 ≥40×40；HUD 文字 ≥11px；点按「建造」展开面板（5 个分类）；面板内单指滑动可滚动；触摸选中工具；画布点按落下建筑；单指拖拽平移；拖拽不误触选中；双击不缩放（`visualViewport.scale` 保持 1）；顶栏「更多」可展开且二级资源不越界；管理面板可展开不越界；管理面板内可触达帮助入口；帮助弹层可开可关；长按画布不选中文本；无 JS 运行时错误、无 404。

横屏 7 项：无横向溢出、画布未被放大、顶栏与操作条在视口内、触控目标尺寸、文字下限、建造栏可开合、无运行时错误。

## 观察到但不阻塞的问题

1. 选好工具后，建造面板 + 造价/缺料预览卡占掉屏幕大半，可点地图降到 **13–20%**（iPhone SE 13%、iPhone 13 20%、Android 360 14%），探索态也只有 32–52%。落点需要反复平移才能对准，建议手机上把预览卡折叠成一行或在放置后自动收起。
2. 横屏 844×390：建造面板横条压住左上角「生存清单」，标题被裁切。
3. 「归园 · 经典开局」提示条与建造栏标题、指南标题有视觉重叠。

## 边界与未覆盖

- 本机无真机与 `adb`，以上为 Chrome 155 的移动视口/DPR/触摸事件模拟：验证的是真实渲染引擎与真实事件路径，不包含 iOS Safari 合成层、刘海安全区、系统手势条、真实手指抖动与按压面积。
- 未覆盖：双指缩放夹取、软键盘顶起、来电/切后台中断手势、低端机帧率。`env(safe-area-inset-*)` 已在 `#town-dock` 使用，但模拟环境不产生安全区，需真机复核。
- iOS Safari 的 `100dvh` 与地址栏收缩行为未在本次覆盖范围内。
