# 有限矿点与永久废坑（0.3.54）

新建矿井和采石场现在会耗尽。放置工具、放置说明和建筑详情始终写明储量与不可逆占地规则，不能靠拆除重建刷新已经开采的矿藏。

## 原版规则与本作适配

- [Banished Wiki：Mine](https://banished-wiki.com/wiki/Mine) 列出单矿最多3500铁或7000煤、可改采矿种、拆后土地不能重建。本作以7000共用整数单位表达：每产1铁扣2单位，每产1煤扣1单位。两种“最多”是替代选择，不能相加；切换矿种不恢复储量。
- [Banished Wiki：Quarry](https://banished-wiki.com/wiki/Quarry) 说明石场有限、拆后坑洞永久保留。本作新石场4000石是小地图适配值，不称为该Wiki的原版数值。
- 沿用现有3×3占地、2名专业工人、9小时基础工段及每批6铁/石或8煤；工具、健康和教育仍影响实际工时/批量。教育提高单批效率，不能凭空增加矿点总量。
- 本片不加入塌方、死亡、山坡放置或新地形系统。永久坑从首次实际采出矿物后成立；尚未开采的工地或完工建筑可取消/拆除而不留坑。这是降低误放风险的本作适配。

## 从储量到库存

1. 接到任务时为该工人锁定矿种、产量和所需储量；活动任务与夜间暂停任务都占预留。第二名工人只能领取剩余未预留部分，最后一批可以少于正常批量。
2. 工人必须步行至真实可达的矿点入口并完成工段，才从剩余储量扣除矿物、生成随身货。被新邻建挤离时先重新走到入口，不能远程开采。
3. 随身矿不再占地下储量，但尚未进入公共库存。仍要实际送到兼容仓库/堆料场，满仓余量保留；预留、已产、入库不会重复计数。
4. 改采矿种、调0工人均不改写已接批次；撤岗要先完成该批并送净已有货。夜间暂停保留预留，死亡、撤销任务释放未开采预留。
5. 剩余到20%及以下提醒准备其他矿点或贸易；到0停产并说明耗尽。矿井剩1单位时不能再采铁，详情提示改采最后1煤。

## 拆除与永久占地

- 未实际产矿：普通取消/拆除，原有建材退款规则不变，不留坑。
- 已产矿：详情“拆除”和地图拆除工具均打开同一确认区。明确丢弃全部剩余矿藏、按普通规则退还一半已付建材一次、永久留下3×3不可建造/不可铺路/不可通行的废矿坑。取消确认不改变矿物、建材或占地。
- 确认期间储量改变、关闭/切换详情、切村或读档后，旧确认不能生效，需要重新查看。重复点击不重复退款或生成坑。
- 已采随身矿继续送仓，未完成工段不再产矿。旧建筑实体被消费，原位生成新ID永久坑，不能再次拆除、再采、重新建设或恢复储量。原矿点本来也不能通行，拆后保持占地阻挡。
- 坑的详情显示来源和拆除时放弃的地下储量。该数值是历史弃矿量，不是可再取的库存。原创透明PNG统一现有手绘、左上光与2:1透视；内部坑壁阴影属于凹面结构，非贴图外投影。448×320画布按50%显示，底角对齐。正常画面不显示诊断占地线。

## 存档边界

- 旧档矿井/石场缺少 `mineralUnits` 时明确显示“旧版无限”，保留原产出与普通拆除。旧石铁混采仍能继续；不会突然耗尽、突然出现永久坑，也不会被新构造函数补成有限值。
- 新点保存剩余整数单位；矿坑保存来源、剩余弃矿量和实体占地。越界/负数储量、不合理矿坑岗位/退款状态会在切换村庄前拒绝。
- 沿用既有存档合同：未完成任务/路径不序列化，读档会重新安排未开采批次，只有任务预留被释放；真实已扣地下矿量和随身实物保留。不会按旧预留重复扣矿或补矿。
- 换季自动档仍可能是本次日界经济事件前的快照，不声称保存了未发生的事件或精确任务/RNG重放。
