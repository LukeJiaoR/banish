# 0.3.6 取消采运标记

基线为 main `7f9c41f68c377e02c1a88e05ec9b9da99948354f`（0.3.5）。本轮仅补充订单撤销操作，不调整任何经济、寒冷或劳动力优先级数值。

## 玩家操作

选中「砍伐」或「拆除」工具，采运面板提供两个独立按钮：取消全部树标记、取消全部矿标记。每个按钮标注当前该类标记数量；取消一类不动另一类。退出工具仍只退出操作模式，不自动撤销已下订单。

## 取消的边界

- 尚未认领的标记移除；正在赶往目标、尚未完成的散工砍伐/清矿任务停止；跨夜保留的同类散工任务不在次日复工。
- 未砍倒的树、未挖完的矿保留。部分劳动已耗时间不返还；重新标记是新任务，不能用取消操作瞬间拿资源或保存部分进度套利。
- 已采出的货物不回滚、不立即入仓、不复制，照原有流程搬运。回家路线、睡眠、已在送仓途中的路线保持原样。
- 只撤销玩家标记所驱动的散工订单；护林小屋和工地清场是独立工作，不因删除同地点的玩家标记而被取消。要改变护林行为用护林面板开关，要取消施工用工地操作。
- 不在按钮处理期间强制重新分配岗位，空出来的散工等正常调度。取消使旧可达性检查失效，避免显示已撤销订单的旧结论。
- 标记集合随存档保存，所以取消后的意图可保存/读回；当前游戏本来不保存进行中的路径和任务，本补丁不改变此约定。

## 验证结果

- 26项取消订单状态/资源/存档回归通过；新增UI事件及静态布局18项通过。
- 独立交错测试164组：取消与完成先后顺序、重复取消/重标、唯一任务认领及真实资源守恒通过。
- 既有smoke224、物流19、存档输入28、家庭清场24、可达标记6、采运反馈14，以及经济UI/选址检查保持通过；93条美术路径/11图透明度、服务器27及安全检查通过。
- 从地图开始的拖动进入新面板会中止；返回地图不会继续旧拖动。窗口级松开事件落在面板上也不会在其下拆除建筑。新手势照常可用。

## UI与验证边界

按钮是稳定的独立DOM节点，帧刷新只改文本和可用状态；取消最后一个标记后焦点不会被重绘夺走。弹窗存在时不可取消后台对局订单，隐藏工具组时焦点返回工具栏。窄/矮视口的采运区域允许滚动。

验证使用Node模拟、DOM桩及静态布局约束；真实浏览器路由仍未打通，因此不宣称键盘/鼠标/视觉的浏览器端验收或真人体验完成。
