# Cancel resource collection

Use the separate Cancel Collection tool and drag a rectangle. Releasing withdraws resource marks only inside that area. On touch devices, choose two corners. There is no second confirmation or global cancel-all panel.

Free-labor chopping/mining tasks associated with those marks are stopped, including paused claims. Existing cargo still travels to storage; independent forestry and construction clearing remain; spent work is not refunded. Outside marks and tasks remain. Exit only leaves selection mode and never cancels previously issued orders.

This slice implements the resource-only subset of the original Banished Cancel Removal area tool; building/road removal cancellation is not added. See [reference, safeguards and tests](direct-resource-selection.md).
