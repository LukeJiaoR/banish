# 酒出口与石料进口

从27649dc接续产业链，只补两项交易目录与物资商目录；不改变人口、产量、死亡、有限矿坑、住宅取暖或固定农田果园牧场。

## 价格与取舍

- 麦酒出口价值8，石料普通买价7、订货价floor(7×1.25)=8。与[原版资源交易表](https://banished-wiki.com/wiki/Currency)及[贸易计算器](https://banishedinfo.com/tools/trade-calculator)相符；不是把石料或酒设为免费资源。
- 石料每船上限100，沿用本作铁、煤的批量尺度，属于明确小地图适配；原版不是固定100。本作物资商每次普通带2种、综合商后续带4种的既有随机货单仍保留，扩大目录不保证每船都有石。
- 三类现有商人都接受酒付款；它不是食物，故物资/种子商的拒收食物限制仍生效。综合商与物资商可卖/接受石料订单，种子商不卖石。酒只作为付款商品，不新增进口酒。
- 例如7酒价值56换8石，订货则10酒换10石。30苹果/梨经现有6小时加工产10酒，价值80，可换11普通石（耗10酒，有3价值舍入损失）或10订货石。果品原价值30，加工差额必须付出工位、实际劳动、运输、果品与机会成本；没有即时兑换循环。原主食30→3/4酒的低收益适配本片不改。

## 内需与实际运输

新旧贸易站默认酒目标均为零、自动购买默认关闭，不自动抽走休闲用酒。玩家明确设置酒备货目标后，商人从通用仓实际领取再搬入贸易站；公共酒与在途酒不能提前付款。出口占用的酒就不能同时用于居民休闲，这是玩家的取舍，不保证出口后内需充足。酿酒的8–48天口粮保留、默认公共备酒30与全镇生产目标继续生效，不因出口绕开口粮保护。

石料交易落入本站库存，再由工人按目标实运回仓；未到仓不能用于建设。2000共享容量含在途占位，付款释放空间后仍需容纳整批石料，满仓/中断/读档保货。订单不预扣物资，只在同一商人回访带货；自动购买只有明确启用后在未来到港尝试一次，依然校验价格上限、本站余额和仓容。

## 存档与验证

沿现有资源字典校验接入，不增加存档版本。旧公共酒库存、旧贸易目标、旧在港货单与订单不补货、不改价。新酒库存/目标/在途货、石料订货与自动购买回执可重复读档，损坏数量在替换世界前拒绝。

- `node tests/merchant-orders.js`：10组；首船目录数量改用当前目录长度，修正早于多个既有商品扩展的硬编码10，不改变首船全目录规则。
- 受影响回归：贸易容量7、自动购买12、订货UI15，及既有果品酿酒/酒馆测试。
