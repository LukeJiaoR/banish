# 道路拖放操作

本轮只调整土路、石路的桌面输入与预览，保留当前路径算法和施工规则。

- 鼠标按住左键拖动：显示实际逐格路线。跨格才重新计算，每次最多展开2000个搜索节点；渲染过程不运行寻路。
- 在已显示的终点松开：提交这条路线的施工订单，工具保持选中，可以继续拖下一段。
- 松手位置未被预览过：更新预览，需按“确认排队施工”，不会自动提交一条未展示的新路线。
- 点选两端仍可预览后确认；手机保持点起点、点终点、确认，拖动和多指不误建。
- 有树时松开只确认清树标记，工人清完后仍需再次确认施工，不自动铺路。树木需求变化时拒绝旧提交。
- 水面、建筑、矿石和山体仍采用已有避障规则。预览之后新增障碍会阻止提交，不会擅自换路线。
- 右键/Esc退出；失焦、页面隐藏、指针取消、进入操作面板、切工具/世界/游戏实例使进行中的拖动失效。已确认的施工不会被取消预览撤销。
- 桥、隧道保留原来的端点指示、松开预览和独立确认。

## 来源与适配边界

[Banished官方Toolkit](https://shiningrocksoftware.com/game/mods/) 的 Game/Help/Buildings.rsc 说明道路使用左键拖放，Toolbar.rsc 说明右键取消工具。本轮借鉴这一操作方式；没有加入Shift切换、原版最短路算法或自动清场。松开提交、移动端两点确认和2000节点预算是本作的具体实现约定。

施工继续由工人逐格完成，石材实运；本轮不改变工时、资源、存档格式、固定农田尺寸、人口死亡或美术。

- node tests/road-planning.js / road-plan-actions.js / road-work-render.js / fixed-farm-preview.js / simple-fields-ui.js：路径、资源边界、渲染和固定田地回归。

这些Node测试不代表真人试玩或物理手机验收。
