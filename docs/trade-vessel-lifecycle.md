# 商船生命周期与最小可见船只

基于 #153 合并后的 main fd86c04e2ef39b57d64d7a8ebe20e8ea82f56d37。生命周期已形成 Draft #155（d964d9e3c90f372ee10e3e5a89b2d68f6f9271e3），本地可见船只增量尚未发布。

## 状态与经济边界

新经典气候村使用存档 v10，在 world.tradeVoyages 内保存独立船 ID、目标站 ID、泊位、进港/停靠/离港状态、路线和格进度。旧 v1–v9 村不自动启用、不升级存档，不改变原到访、订单、货物或库存。

- 进港船从显式主河入口沿正交水路前往固定泊位。航速为每日16个水格边，是本作适配，未声称原版速度。日结推进位置，无预测位置或逐帧插值；小尺度程序绘制的木船与青玉顶篷沿当前路线朝向，水面层在桥面和岸边物体之前绘制。船只没有新增拾取，交易仍只经贸易站入口。
- 仅到达泊位、到达目标日期且站仍有效，才同步消费一次到港事件：产生一张货单、消费该商人的订单、增加轮次，并沿用已有一次性自动购买。直接调用 arriveMerchant 而没有当前 world 的合法进港船，不会结算。
- 只有停靠实体与本站货单的船 ID 匹配，交易入口才允许交易。进港或离港船不能交易，也没有玩家可领取的途中货物。
- 停靠仍为12日。下一目标到港日仍为实际到港日加16日，不把16日改成发船间隔。已知入口航程用于提前发船；过长航程只能延后实际到港，不能伪装准时或瞬移。初次目标沿用原有 nextMerchantDay 初始化规则。
- 每站最多一艘进港、一艘停靠；离港船独立存续，不堵住后续发船。离港驶向显式主河出口，不反转入口路线。到出口后移除实体。
- 拆除贸易站仍须先搬空本站库存；拆站使已有进港/停靠船从当前位置驶向出口，未到港订单不会结算。船不依赖被拆建筑继续移动，不改市民携货与拆除退款规则。未卖出的商人货单随离港失效，不记为镇库存。

## 日结和保存

endDay 更新日历后先完成全部船状态与到港自动交易，再调用可能自动保存的 onSeasonChange。world 的 lastDay 日结守卫确保该日只执行一次。普通贸易经济日结对 v10 跳过旧式瞬时商人生成。

v10 严格包含 v9 主河以及 v8 果园/霜损/气候/取暖规则。解析对版本标记、船字段、ID、路线、进度、到港日期、目标站与停靠货单关联进行校验。路线须匹配当前水图的确定性入口/出口路径。加载只重建数据，绝不调用到港或自动交易，也不为离线时间补跑。

## 定向验证与限制

在仓库要求的 Node 24.22.1 运行 tests/trade-vessel-lifecycle.js，覆盖实际日结下三阶段存读、到港订单和自动购买仅一次、换季自动保存、进港/停靠拆站继续离港、长航程延期、坏档原子拒绝，以及从真实 v9 引擎导出的在港货单/库存/订单保全。存档测试仅允许既有解析器把空 merchant:null 规范化为字段省略，其他数据仍完整比较。独立静态审查发现并修复了伪造零日航程的已靠泊存档边界。

同时运行主河资格、气候、取暖、自动交易、订货、容量、两项气候 UI 和存档输入回归。旧 v8 回读使用真实前代引擎；两项 pre-climate 和一项 pre-heating 历史引擎检查仍明确跳过，没有算作通过。

没有浏览器/手机/桥下遮挡或可见船只验收，没有全生存长跑，也未专门覆盖多个站同日到港组合。船按日推进，本片虽已有最小可见船只，但尚无逐帧插值；离线原生 Canvas 像素不等于浏览器或 #138 完整验收。没有绕过已知预览入口阻断。

## 可见船只增量

仅沿用现有 Canvas2D 和代码原生小物件约定，没有生成或下载新贴图、没有引擎迁移。暖木船体、浅青玉篷和克制尾迹参考 A 的整体色彩，无法宣称已达到 A 的细腻场景美术。测试工具 tools/render-trade-vessels.cjs 从真实日结状态输出三阶段、两档缩放的离线原生 Canvas 图像及四向/桥面遮挡对照。船只位于水格中心，旧无船世界不凭空画船。真实浏览器、手机、岸边遮挡复杂组合与点击体验仍待验收。

首版视觉结论为功能可见、视觉未通过：船体大块纯色、薄平篷顶，明显简于现有木建筑。后续一次局部改进已加入收底船舷厚度、分层木板/甲板缝、弧面篷布/木支撑/折线和立体绑绳货箱。局部结构改善，仍不作为整套 A 成品或浏览器验收通过。行进船只有两条静态尾迹线；没有随时间动画的涟漪/波纹，没有船夫/人物动作。后续可局部提升木纹、篷布体积/明暗和低成本水线，并在真实浏览器验证尺寸/遮挡；本片不扩展船生命周期、交易规则、引擎或重画全景。

结构改进对照：tools/compare-trade-vessels.cjs 在相同日数/位置/方向/缩放下输出前后并排图，并逐像素检查六张场景中心左右各100px、上下各70px的对照矩形之外像素未变（不单独断言矩形内紧邻船的水面未变）；四朝向/桥面图单列。只修改绘制函数和验证文档/工具，没有修改生命周期、存档或经济规则。
