# 衣物配送与换衣（v0.3.59）

## 如何启用

新局与旧档默认仍在穿坏日从公共成衣库存直接领取。已经启用粮柴真实配送的旧村也不会自动改衣物规则。
在市政厅或市场原有“全村真实配送”区域，启用家庭配送后可看到“加入衣物配送”。先导出当前存档，核对公共普通衣/暖衣、衣物耗尽人数和七日内需换衣人数，再二次确认。

这是一次性、不能切回远程领取的选择。**不扣取、划拨或赠送任何衣服；已穿的种类和剩余耐久完全保留。** 取消无副作用，导出后须重新确认；换档、住户/耐久/库存/日期变化会使旧确认失效。尚无通路、采购者或家中衣物时，不能因公共库存有货而立即穿暖。

## 实际循环

- 裁缝沿用已有的真实领料、加工、送公共仓流程，配方、用工、产量不变。
- 货商真实领取衣服补到市场；家庭健康成人与粮柴同趟采购，衣服到达住宅/宿舍/临时补给点后才成为家人可用现货。无人能采购的家庭仍由空闲健康成人协助，不派学生或病人购物。
- 家中按未来七日内将穿坏或已经无衣的家人数备换；货商按范围内住户人数备最多十二件。库存和已背出的来货都算占位，不重复派购。
- 实际取货优先暖衣，不足才普通衣；日界穿坏也先用本地暖衣，再普通衣。未穿坏的普通衣不会被暖衣提前替换，仍穿一件、只扣一件。换上后沿用四十八日耐久和原有冬季保护。
- 取卸、走路、夜休、道路与冬季步速继续生效。七日提前量、十二件市场计划和家庭代购是本作适配，不是原版固定数值；近仓或合理市场布局有用，长途或断路仍可能来不及换衣。
- 衣物与食物、燃料共享原市场容量和携量，衣物只搬整件。冬季先取燃料，再按需求取衣服和食品；衣物计划不是保证到货。露天堆料场不能供应衣物，贸易站待售品也不能供家人直接领取。

## 库存、死亡与保存

公共、市场、家庭、在途、回收物资的衣物分别计量；已经穿上的衣物不再属于可用库存。启用后，普通/暖衣生产目标计入已配送但未穿的实物，排除火情封存和正在穿着；工具仍沿用原全镇工具池。

取消配送、目的地拆除/改建、迁居、采购者死亡和火情沿用实物保全与回收链。已穿衣不会因迁居重置或死亡退回；携带的未穿衣会留下可回收实货。满仓只剩半件空间时保留整件等待，不能把半件衣送到家或保存成半件配送货。屋内存量烧毁才计损失，已经运出的物资不受重复扣除。

旧五类生活库存存档只补两个零值衣物栏，不创造衣物；旧在途粮柴照常完成。保存保留新选择、未穿存量、混货及实际换衣记录，重复载入不重复领取。衣物配送需要先启用家庭配送，非法或残缺新记录会原子拒绝，不放宽旧公共资源合同。
