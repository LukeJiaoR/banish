# 仓库与建筑入口择路（0.3.23）

搬运按道路/野地预计通行时间，在全部已建成仓库的合法入口间作一次多目标搜索；生产和施工同样选择真实可达入口。共享仓储容量、生产配方和运输速度保持现有规则。没有可达仓库时石铁背货继续等待，不会在任意空地假交货。

派工直接复用刚得到的路线。世界、起点、路网/建筑版本、目标身份或施工状态变化时拒绝旧提示，重新选择合法目的地。提示不写入存档。伐木屋取木阶段只计算去仓库的路线，取木后再从实际位置规划回工坊。

搜索堆保存不可变优先级，避免节点更新后破坏堆顺序。扩展上限按实际闭集格数计，最多地图格数；过期重复堆项不消耗此预算。128×128、两角仓库、475 格稀疏道路的复现从错误“无路”恢复为到右仓库的 51.6111 小时路线（左仓库 52.3531 小时），携带的 9 铁进入真实搬运且没有提前入库。

## 已验证

- 主要候选的 13 项定点测试通过，含独立 Dijkstra 对照、真实派工搜索次数、旧提示失效、满仓保货；既有 smoke 225 项通过。
- 最后预算修复只复跑上述 128 图单个阻断复现，按本阶段要求未逐小改重跑全量矩阵。独立审查另行复核该增量。
- 实际移动对照：较近野地仓库耗时约 4.880 小时，较远沿路仓库约 3.847 小时，选后者。
- 早期运行候选的 3 种子、各有路/无路五年对照全部无死亡；总寻路次数和节点量随城镇人口/发展轨迹变化。该数据不是最终增量的全量生存或手机性能验收。

预计时间沿用格中心连续速度模型；实际帧步长、小数起点和途中季节变化会有偏差。手机和真实浏览器仍未实测。路网改变不会主动重规划所有在途市民；本片没有更改住房选址或全局劳动力调度。
