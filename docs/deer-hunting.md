# 鹿群与实际狩猎（0.3.70）

跟踪：[Issue #77](https://github.com/LukeJiaoR/banish/issues/77)。实现前基线为 [main 72deabe](https://github.com/LukeJiaoR/banish/tree/72deabe6ff42fe8e627a2590b963ba06ee5ea0df)，紧接可变果园 #76。

## 原版依据与矛盾

[Hunting Cabin](https://banished-wiki.com/wiki/Hunting_Cabin) 的专门说明把狩猎与遇见鹿关联，并限定每屋两个月一次成功猎杀，同屋工人共用间隔；猎获肉与皮需要送仓。重叠屋各自计时，但不能重复杀同一只鹿。

[Deer](https://banished-wiki.com/wiki/Deer) 说明没有永久过猎耗竭，田地内的鹿不降低收成。[Tutorials/Tips](https://banished-wiki.com/wiki/Tips) 又称可见鹿是装饰，这与专页的实际相遇描述冲突。本作明确采用专页的“玩家看得见并能够到达的猎物”玩法，**不声称还原了已实测验证的原版内部生态算法**。没有新增野鹿啃庄稼、永久灭绝、捕食者或随机猎人事故。

## 能做什么

- 在地图林边观察野鹿，按鹿所在位置选择猎屋。查看猎屋或建造预览的圈内数量、未被追踪数量及当前门外可达数量。
- 猎人实际走到鹿所在格工作。鹿被有效任务追踪期间留在原地；放弃任务、死亡、目标失效后不留下永久认领。仅完成一次合法任务才消耗该鹿并产生一批肉皮。
- 同屋成功后等待8日；第二名工人不能绕开全屋计时。附近另一座猎屋可独立追踪其他鹿，不能复制同一只猎物。
- 肉与皮先属于猎人随身货，不是公共库存。抵达可达通用仓才逐项入库。仓满、无仓、通路阻断时继续保留；岗位减少先结清已接批次/运输。皮革目标不把已获得副产物消掉。
- 新猎获或遗留肉皮的运输者死亡时，未送仓的真实肉皮计入猎屋详情的全镇猎获损失，肉类另外计入现有食物账本的丢弃量，发出提示。没有远程赠回库存，也没有无记录抹掉携货。

## 明示的本作数值适配

| 项目 | 本片行为 |
|---|---|
| 日历 / 间隔 | 48日为一年，两个月折为8日；从实际成功猎杀时刻开始，精确到小时 |
| 猎屋合同 | 仍2岗位、2×2占地、44木10石、80施工、建筑原点±12格的方形工作圈；不套用原版4岗位/更大范围 |
| 人口 | 全图24个鹿槽，实际可居住森林不足时部分等待；鹿不是仓库资源或可交易牲畜 |
| 栖地 | 无水、石头或建筑占格，附近两格有树；不要求成熟树数量、不按林量直接计算每鹿产出 |
| 活动 / 补入 | 每日最多邻接活动一次，栖地中心±4格；成功猎杀后8日再补入合法栖地。清林或建筑挤占时退出并等待回归，原栖地不再可住则寻找其他合法森林 |
| 单次劳动 | 基础5游戏小时，复用教育、健康、工具等现有劳动约束 |
| 单鹿产物 | 未受教育160肉/4皮，受教育200肉/6皮；复用当前工具规则锁定批次数量。不是Wiki给出的精确单鹿数值 |
| 美术 | 原创透明野鹿，显示宽26，羊24/牛32/成人高17的相同尺度；原2:1透视、左上光、暖土色手绘，原动物不改画 |

鹿槽是补充机制，并非死亡鹿复活的叙事；没有生育年龄、种群遗传或生态框架。无合法栖地会继续等待，不在水里、建筑里或仓库里凭空生成。

## 存档保全

只有一个狩猎引擎，旧村加载后未来的狩猎也采用新鹿群和8日间隔；不是维持旧每趟按树数发肉的产量保证。依赖狩猎的大村应查看食物账本与鹿群通路，可先保留导出档。旧格式从未保存进行中的工作任务，原读档合同就是重派工作；本片没有为未完成旧任务兑现虚拟产物。

- 旧档首次读入：按地图和既有猎屋初始化野鹿，尽量照顾既有合法猎场；不消耗村庄原随机序列，不更改人口、资源、既有携货数量或两人岗位。原无其它明确货批标记的肉皮携货改用保货运输标记，断路/仓满仍保留。旧档没有原产屋记录，不能用当前岗位或已拆建筑倒推来源，统一记来源0并在UI称“遗留肉皮”，不假称一定来自鹿。已有牧场、作坊、家庭配送等明确货批不改。
- 当前格式：固定鹿槽、位置、栖地、代次、回归日、移动日、每屋冷却、真实携货和累计损失全部保存。读档不重填已被猎杀槽位，也不重置冷却。未完成追踪按照原存档合同重派，不带来额外肉皮。
- 部分缺字段、重复鹿、非法落点、伪造来源/货种、超时冷却等不合法数据拒绝。候选世界完整验证后才替换当前村庄；失败保留当前游戏与自动档。

## 验证边界

针对本片运行真实模拟与实际DOM API检查，并用实际Canvas绘制代码离线对照鹿、原牛羊鸡、市民、树和猎屋的尺度。离线检查不等于真实浏览器或手机试玩；既有浏览器本地URL访问限制没有绕过。

最终验证命令与独立审查结论在关联PR记载。没有新增CI、性能平台、气候或生产部署。
