# 缺料也可规划建筑

合法占地现在可在公共木、石、铁不足时确认工地。缺料显示“可规划，等待材料”；红色仍表示地形或占地不合法，缺料采用警示色。固定农田、牧场、果园、可变面积工地和木桥使用相同规则。

确认不扣也不预留库存，不生成材料。沿用既有建材实运：工人到仓取走实际材料，送到工地，齐料后才施工；没有可做工作时不占用施工岗位。补料后按原调度恢复。清树、库存容量、道路可达性、食物劳力保护与暂停优先级不变。

取消只退实际已送到的材料；在途货仍实际退仓。零料工地取消退款为零。开工后的回收比例不改。现有存档格式与已付旧工地迁移不改，付费即时创建仍必须足额付款。

土路本来不需建材，石路和隧道本来已能缺料排队，本次不改这些施工规则。桥和隧道完工前仍不可通行。房屋升级与火后重建属于独立操作，本次未改变其确认要求。

验证：零库存失败复现后修正；测试涵盖等待、补料、部分实运、保存载入、零料与部分料取消、争用、重复确认、非法占地、固定/面积田、桥梁及即时付款保护。沿用实运全套测试继续覆盖在途取消、死亡、仓满、旧档和不重复结算。离线逻辑/DOM/画布测试不代表真实浏览器或手机视觉验收。

回归维护：`building-completion` 的 DOM 替身补齐现有面板要求的 `classList`；`pasture-area` 的非法地形测试改为损坏存档内的权威地形，而非当前世界。两项旧测试问题均在 main `985a6a2` 独立复现，不修改运行逻辑或放宽断言。石路文案断言同步为“可规划”。
