# 0.3.4 玩家体验修复

汇总数值与源码/策略哈希见 [可复核结果](player-experience-results.json)。

基线：main `c699714`。本轮处理存档完整性、输入安全、跨代家庭、清场公平性以及新手选址与窄窗口入口；不增加贸易、灾害等新玩法。

## 玩家可见变化

- 道路随存档恢复；旧档没有道路字段时保留兼容。
- 导入先验证再提交。坏档失败时保留原对局，不让失败导入触发一次破坏性的自动保存。
- 在反馈、存档及说明窗口中，打字不会触发速度、暂停或移动快捷键；长按暂停键不重复切换。
- 帮助阅读时暂停，退出恢复阅读前的暂停状态。首冬清单持续展示现有粮食可支撑天数、入冬倒计时与当前建设顺序：持续食物 → 近仓柴火 → 逐步安家 → 工具与下一代。
- 选址预览标出材料（现有/需要）、与生产逻辑一致的方形工作边界、树木/成熟林或水域条件。低产选址保留自由，另用文字说明；仓储距离是当前地形可达路线步数估算，不是承诺年产量。
- 工具栏在窄窗口可横向滚动；按钮有可见键盘焦点，正在操作的信息面板不会被定时刷新夺走焦点。地图选址仍需鼠标或触控板。
- 保留现有手绘素材及配色，未替换美术风格。

## 验证边界

本轮使用 Node 隔离模拟、DOM stub 和静态布局约束检查。它们可以验证逻辑和回归，不能替代浏览器的 768/1024/1280px 点击、滚动和实际视觉验收，也不能证明真人觉得好玩。当前运行环境的浏览器路由/本地浏览器 socket 受限，不绕过权限；实机验收仍应单列为未完成。

## 家庭与清场规则

配偶、父母、祖父母及直系祖先分别保存，搬家或长辈死亡不抹掉亲缘。18岁以上、未在读且无伴侣者可与符合亲缘规则的另一成人组成新家；成年子女需要空屋，不挤走父母。禁止直系、兄弟姐妹、同父异母/同母异父、共同祖父母的堂表亲配对；仅共享更远祖先的旁系不永久禁配。出生依赖同户有效双向伴侣、住房、粮食和原有生育概率。修正未指定性别的初始孩子姓名与实际性别不一致的问题。

旧档没有亲缘字段。只恢复能由旧版创建顺序严格识别的初始夫妇（原家庭ID紧邻其两位父母ID，且成员顺序与性别匹配）；该模式下补齐子女父母。无法可靠识别的旧同户成员保留住房与成员归属，以原户作为保守亲缘屏障，不仅凭同居猜夫妻。这类旧户可能停止生育，空房后可与其他非近亲单身者成家。直接用0.3.3生成的初始15人快照迁移，5对初始夫妻及5名子女双亲已独立验证。

建筑/农田下单保留树木，不直接给木材。工人使用普通砍伐任务参数（未受教育、有工具时每树8游戏小时），携木到仓，清完占地后才施工；工具与教育修正照常。实体工地从可达边缘清树，农田逐树寻路。未劳动取消返还全部实际支付建材；开始清理/建造后拆除退一半，未砍树保留。内部免费建筑不会凭拆除生成退款。

## 已验证范围

- 存档/输入28项，家庭/清林24项，既有smoke224项、物流19项。
- 原文坏档备份失败也不覆盖原档；临时局持续显示自动保存保护状态。本机存储被浏览器禁用时，存档管理仍可导出当前局文件。
- 独立复核：清场工人正搬运时取消实体建筑/农田，剩余树及货物保留，货物恰好入仓一次；读取真实旧版快照恢复初始家庭；弹窗焦点、范围边界、暂停免费放置缓存等回归已修。

## 五年真实经济矩阵

固定原有策略，种子1–8运行 normal / original / neglect / no-fuel / overexpand 共40场，65/65验收项通过。正常策略八种子均五年0死、无饥饿人日、无工具断供；末人口17–24。忽略生存的8场仍全部第20天饿死；不供柴全部发生冻死；过度扩张全部灭村。修复不保证错误策略存活。

冻结规则后保留种子41–48使用原adaptive-mining，46/48通过，不能写成全过：七场0死，44活到五年但第4冬冻死8名儿童、末人口12。独立诊断发现d144旧脚本26格找木范围内非食物林为0、没有待砍标记，但全图仍2734棵非食物林树可达，属于脚本未向外找木。原秋季预警只短暂显示，现在清单持续提示木材耗尽、扩大可达砍伐/补种及秋冬剩余取暖缺口。

同一长期规则对44仅做五年，虽避免冻死，但出现4名饿死、82饥饿人日；不称为补救成功。单独找木范围对照改用同样的方形食物林保护，避免把保护区修正与扩大范围混为一个变量：

- 仅26格局部可达树：11次冻死，原木产156，最终木0/柴0。
- 局部可达非食物林耗尽才扩范围：d105首次标记约27格外树，每批最多2；真实原木产314，末21人、食305、柴87、工具31，0饥饿/断工具/冷屋人日。
- 两臂均在d45发生同一名无房儿童冻死，早于d105范围干预；扩范围后无新增死亡。不说成“零死亡通过”，而是证明长期断柴可用正常操作恢复。
- 原adaptive脚本d120已提示柴火60/需90，d168提示0/90，比d189首例灾难提前21天；现在游戏清单持续显示缺口与扩大砍伐/补种建议，避免短toast一闪即逝。

测试的`--assert`才会在失败时给非零退出码。长期检查明确包括无饿死/冻死（自然老死除外），短期不适用的跨代/学校检查不虚报PASS。独立41与44负结果都保留。
