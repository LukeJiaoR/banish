# 主河与贸易水路资格：第一片

## 原版依据与未恢复的细节

来源为 Shining Rock Software 官方 1.0.7 Mod Kit：
https://shiningrocksoftware.com/game/mods/
https://shiningrocksoftware.com/download/BanishedKit_1.0.7.170910.zip

- `resource/Game/Help/TradingPost.rsc`：贸易站须建在河或湖边；商人乘船而来，不通主河的湖泊没有商人；到港后交易。
- `resource/Template/TradingPost.rsc`：放置位图含 `DeepWater`，并引用独立 `TraderBoat`。本作小建筑没有原版12×11脚印，不照搬它的泊位尺寸。
- `resource/Template/WoodBridge.rsc`：桥有独立 `PathType=Bridge`。本作水图与居民图分离，桥的所有施工状态都保留底下水通路；这是明确的适配选择，未声称恢复原版施工时船舶碰撞。
- `resource/Game/Terrain/Valleys.rsc` 与 `Mountains.rsc` 分别配置溪流和湖泊。主河生成与船的寻路实现未公开，不能从边缘水格反推原版主河。

不使用原版图片、模型或声音。深度、桥净空及窄水道阈值未知；本片把连续正交相邻的水格作为可航图，沙滩不能通船。不是将所有溪流禁航，也不是将任意接边水体称为主河。

## 新村与地图合同

- 仅通过现有新村流程建立的经典气候村启用：地图版本4、存档v9；Mild/Fair/Harsh、128/192格均使用同一版本。山地继续地图版本2、气候存档v8；历史无气候程序开局保留地图版本3。
- 新图先沿用经典地形和镇址选择，再在镇址以北或以南26格生成横贯地图的主河。中心线弯曲幅度2格、每段周围2格宽缓冲构成至少5格航道。这些数字是本作适配，不是原版数字。
- 主河在储物车、居民和鹿群落位前生成；不切过近镇14格矿物保底区。河道内树和矿在生成阶段移除，不产生库存。此片会改变新村远处地形与资源分布，尚未进行平衡/视觉验收。
- 保存显式中心线、入口、出口及水路版本。读档要求中心线与种子/镇址的版本化生成规则一致且河道全是水面；不通过重新生成整张地图修补错误存档。
- 连通水体通过主河入口的四邻接水图取得资格；孤立池塘、仅角接的水体不通航。原始水数组在新村生成/权威读入之后不再修改。派生寻路缓存按世界隔离，不写入存档；未来如加入改水地形的功能，必须显式使缓存失效。

## 泊位、交易和第一片边界

- 新规则贸易站需要侧边相邻水格，角接不算泊位。创建时优先确定一个通主河的侧邻水格，否则固定一个孤立湖泊泊位；泊位随该建筑保存，读档不重新挑选。
- 可以在孤立湖边建贸易站，详情会解释无法到访及待售目标设0搬回货物。库存、工人实背、搬回、订单和价格不变。
- `arriveMerchant`在使用随机数、消耗订单、增加来访轮次、生成货单及自动购买前检查路线。不能只在UI禁用而留下直接调用旁路。不到港仍由原有`currentMerchant`/交易报价守卫拒绝交易。
- 水路失败不消耗待来访订单、不触发自动购买、不增加轮次、不远程补入货物。可达时仍按现有日期到访，未新增船速或经济等待时间。
- `tradeWaterRoute`提供入口至泊位的网格路径，独立于Canvas/任何未来显示引擎。**本片没有在途船实体、移动画面、进港/离港状态或途中存档**，不得描述成真实航行完成。#138保持未完。
- 桥保留水下通路；居民是否能走桥仍用原来的建成状态与陆路规则。原版精确深度/碰撞公式未恢复。

## 存档与旧村

v9严格保留v8的气候、温度取暖、果园冷害和提前采果版本合同。水路标记仅v9/mapVersion4接受；缺失/额外字段、错误主河、非侧邻泊位、孤立泊位却已有到港货单会在替换当前世界之前拒绝。非贸易站不能带泊位。

v1–v8加载与再保存不加水路字段、不改地图版本、不强制升到v9，不改到访，不删除货单或迁移任何库存。旧程序应拒绝v9，不能回退版本号隐藏新规则。山地新村也不启用此片。
