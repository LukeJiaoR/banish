# 真实鹿群、移动追踪与年度恢复

父跟踪 #134，实施 #135。基础为 main b15647a（包含 #132 动物表现和 #133 缺料建筑规划）。

## 官方依据与适配

[官方工具包](https://shiningrocksoftware.com/game/mods/)的1.0.7配置：PopulationDeer 的8格觅食区/64格大区、5–10群规模、1月停留/12月繁殖；HunterLodge 的2月共用猎杀间隔；Venison/Leather 低高产量160/200和4/6。引擎完整路径、迁徙/繁殖算法未知，不能称逐行复刻。

本片采用3群、各8个槽位（总上限24），保留当前猎屋2岗/2×2/44木10石/±12方圈、48日年中的8日共用冷却，以及现有教育/工具/劳动与肉皮实运。群体四日选择一次局部新草场，候选距当前草场每轴至多32格；鹿沿既有合法导航边行走，速度0.7格/游戏小时，短暂停留后继续觅食。以上是本作适配，不是原版内部精确值。

每年同一繁殖日恢复至 min(8,max(5,现存数×2))；无合法草场/空格则不补。灭群后的最少5只是种群恢复抽象，不叙述为死鹿复活；不新增年龄/性别框架。旧缺席鹿至少等待原回归日且只能在之后年度事件恢复，不加载即补满。不追溯多次繁殖、不永久耗竭，亦不保证任意猎屋布局都达到年产上限。

## 真实动作与守恒

- 鹿保存当前格、路线与格间进度，渲染取真实插值位置；减少动态仅关闭装饰摆动，不冻结模拟。
- 猎人追踪变化的目标格并重新寻路。只有到达同一位置、目标不处于跨格移动，才能处理猎物。只有在场工作的猎人可暂时留住猎物；睡眠/挂起/远处认领不能冻结鹿。
- 成功击杀仍原子校验唯一猎物/代次/全屋冷却/任务完成，肉皮先进入真实携货，再送仓；暂停、死亡、满仓、读档不能额外获得货物。
- 清林不让活鹿消失，鹿可通过非觅食地，改向合法草场。建筑规划不能覆盖正在站立/跨格的鹿；未来路线被占用时重新规划，不穿建筑。现有山体、桥和隧道合法边用于真实移动。
- 不新增捕食者、庄稼损耗、猎人事故；不改变牧场动物数量/生产、默认补给、人口和营养。

## 存档

新增独立 wildlife v2 与鹿的 herdId/route/progress。旧鹿档先按原格式严格验证，再只添加群归属与空路线；现存位置、缺席日期、冷却、货物、库存和损失不重置。无鹿的更老档沿原初始化合同建立鹿群。

当前格式保存格间进度和群草场/迁徙日/繁殖日/时钟。非法归属、群数、跨格、进度、时钟、缺失字段等原子拒绝。已领取市民任务仍沿原存档重排合同，不声称完整任务回放。旧程序会因鹿字段不认识而拒绝新档，不把新生态当旧数据偷偷读取。
