# 伐木屋原木与柴火运输（0.3.46）

依据 [Banished Wiki: Wood Cutter](https://banished-wiki.com/wiki/Wood_Cutter)：伐木工需要取原木、加工与送柴，邻近堆料场和道路会减少运输时间，普通/受教育工人每原木出3/4柴。本作继续采用1名工人、每批2原木、加工3.5游戏小时产6柴/受教育8柴；工时、仓容和时间尺度是本作适配值。

## 玩家能看到的变化

- 空手到可达、能接原木的通用仓或堆料场，才整批领取2原木。库存立即少2，居民显示携木回屋，材料不能被建设、贸易或其他工人重复使用。
- 工人实际回到伐木屋合法入口，使用同一随身批次劈柴。完成时把原料替换为柴火，不再次扣木；必须实际送仓，柴火才可供住房燃烧。
- 面板分开显示公共原木/柴火、未取料、携木回屋、屋内加工、夜间暂停、原料退仓和已产未入库柴火。未入库柴不能用于供暖。
- 近堆料场与道路有实际收益，远途搬运降低供暖产能。生产目标只是接新批次的停产线；不能拿3.5小时直接推算全年产量或承诺一个工人永远够全村用。
- 仍使用全镇公共库存，堆料场图上的木堆不是独立当地库存。没有任何仓库的历史村庄保留原有兼容入口：在真实伐木屋端点领料，不远程扣料。

## 中断、满仓和存档

在途原木绑定当前货批，原料不足时不创建批次；回屋路线消失、拆屋或任务取消，未使用木材实际退回可达兼容仓。两边全部断路时保留同批，按现有节流重寻；复通后交仓。夜间休息挂起当前任务和货批，天亮实际走回工作点。降为0工或降低目标仍按已有规则收尾有限已接批次，送净才释放岗位。

本片原木和新产柴火保留满仓余量，部分入库只扣实际接纳数量。拆屋、重复完成、旧世界回调和反复读档都不得重建原料或重复生产。保护标记跟随这一个货物对象，不继承给下一次普通采集；历史普通原木/柴火没有被追溯改为新批次。居民死亡仍沿原有背货处理，本片没有增加全局死亡掉落系统。

存档保存实际携货及标记，不保存加工任务、路径或剩余工时。读档后的未完成原木先退仓，不赠送柴火也不再次扣原料；已经完成的柴火继续送仓。严格校验原料种类、数量上限2、柴火上限8及互斥标记，坏档原子拒绝。沿用既有换季自动存档时点，不宣称逐帧确定性回放。
