# 鸡牧场与鸡蛋物流

版本 0.3.64，2026-10-12。接续原有牛羊牧場、贸易站、真实家庭补给和三营养组，补齐第三种原版牲畜及独立鸡蛋物品。

## 原版依据与本作适配

- [Pasture](https://banished-wiki.com/wiki/Pasture)：鸡与牛羊同属牧场牲畜；鸡提供肉与蛋，开局无牲畜时经贸易获得；原版每只鸡需要6格。
- [Chickens](https://banished-wiki.com/wiki/Chickens)：常规购鸡价值400；需要牧场。
- [Eggs](https://banished-wiki.com/wiki/Eggs)：鸡蛋是独立食物，交易价值2。该页并未确认吃蛋影响繁殖，因此本片不建立“吃蛋扣孵化”关系。

本作沿用固定6×6小地图牧场，容量24只鸡（原牛10、羊12不变），默认保留8只，可设2–24。容量、每只每日0.5枚蛋、96枚待取上限、每趟20枚、鸡繁殖进度每日增加鸡数/48、每次超额屠宰6肉，都是本作节奏适配，不宣称原版数值。鸡肉计入既有“肉类”库存，鸡蛋单独叫“鸡蛋”，不冒充鸡肉。生鸡经既有待安置牲畜栏放入同种牧场，不扩建动物运输系统。

## 可玩的链路

1. 普通商人可卖鸡、鸡蛋和肉；鸡价值400、蛋2、肉1。鸡进入待安置鸡栏，蛋与肉分别进入贸易站实货库存，不直接加公共粮。既有备货、退仓、订单、到港自动购买均支持这三项；专项商人保持自己的目录与付款规则。
2. 空牧场选择鸡，放入已购买鸡，派牧人。牧人须真实到场完成原8小时照料；饥饿或患病者不能完成新鸡场照料或屠宰；饥饿牧人仍可实际拾取已产鸡蛋送仓自救，不续照料日，居民生存与治疗仍优先。使用已有两日照料有效窗口，失去照料后暂停繁殖与产蛋；工位设零立即暂停新产蛋。没有新增无依据的“消耗粮食喂鸡”或动物饥饿数值。
3. 至少2只才能繁殖，单鸡仍可下蛋；每日仅结算一次，未满一枚的进度保留。产物先存牧场，公共仓、家庭、贸易站不能隔空取用。
4. 牧人实背鸡蛋到可达通用仓，最多20枚/趟。仓满或断路保留在场内或背上；部分交仓后余货仍在，不丢弃。鸡蛋或总食物目标只暂停新产蛋，已有蛋继续运输。
5. 超保留量的鸡由牧人实际屠宰，每只6肉，待送产物先运完再屠宰。鸡不会产毛或皮。现有分群条件与确认保持，源场已产蛋及不足一枚进度留源场；新目标场须重新照料。
6. 待取蛋阻止拆场；全部取走后可拆，活鸡回鸡栏，已背出的蛋继续送仓。空场换种仍须没有旧产物、在途货或旧任务。

## 饮食、库存与存档

- 食物从3个物品扩到4个物品：主食、蔬菜、肉、蛋；营养仍是原3组：主食、蔬菜、肉/蛋白。
- 一餐按实际可用营养组等份分配，再在肉/蛋之间分配蛋白份额。拥有肉和蛋不会多算一组幸福/健康或发展挑战，也不会挤掉等量主食与蔬菜。
- 自动供给直接扣真实公共物品；已开启家庭配送的村庄继续走仓库/市场→家庭实背链。物品流水包含鸡蛋，合计只计一次。
- 旧存档缺鸡、蛋、私有库存蛋项、流水蛋项时均补零。原三种食物数量、牛羊、在港商船及既有供给模式保持。新鸡场的产蛋日与分数持久化；不补发历史鸡蛋。
- 不合法容量、日期、进度、食物合计或跨物种数据在替换当前世界前拒绝。
