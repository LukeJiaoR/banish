# 牧场分群扩场（0.3.42）

羊牛繁殖到一定规模后，可以把一半分到第二座牧场，不必重新等商船购畜，也不必拆掉旧场才能取回牲畜。

## 操作与限制

在原牧场面板选择同物种的已建成空场，查看方案，再确认分群：
- 源场至少10头，分出 floor(头数/2)，源场继续保留至少2头种畜。12羊分为6+6，11羊分为6+5，10牛分为5+5。
- 默认保留量8会使牧人屠宰超额牲畜；想达到分群规模，先把源场保留量提高到10或容量上限，再等待繁殖。
- 目标必须是另一座空的同种牧场，有足够容量，且没有旧羊毛、待送肉皮、当前/暂停牧作任务或在途产物。不同物种先在空场明确切换，不能混养。
- 查看与确认均用当前寻路器核实两场连通；未完成桥不可当通路。面板日常刷新不跑寻路。方案期间头数、繁殖进度、保留量、日期或道路状态改变，要重新查看确认。
- 两场保留量和用工不会自动调高。目标保留量太低时，后续牧人会正常屠宰超额牲畜，确认方案会提示该数量；新场没有牧人照料则不继续繁殖。

本作已有牲畜按牧场群体数量管理和直接安置的合同。本次确认直接改变两个牧场的群体数量，没有逐头赶路、动物运输队或搬运计时；实际连通性是动作前提，不能表述为已有赶畜动画。

## 守恒与归属

分群不创造、购买或屠宰牲畜，不经过待安置库存。两场总头数和原待安置数不变。

源场累计繁殖进度按分出头数比例划给目标。若旧空场已有有效进度，将两处进度总量保留；目标超过1的部分留回源场，仍满足原存档每场0–1的范围。这个比例分配是本作适配，不声称原版精确算法。新场不复制源场的“今日已照料”记录，必须由当地牧人真实到岗。

源场已剪/待剪羊毛、已屠宰肉皮、牧人现有任务及携货仍归原场。不用分群复制副产物，也不把在途肉皮换成新种畜。新场后续正常照料、繁殖、屠宰、搬运；两场独立用工。

重复确认会因为源场不再符合原方案且目标不再为空而拒绝；换村、读档、拆除或换选中的旧按钮不可影响新实体。没有新增存档字段，分群结果沿用现有头数、繁殖进度和物种保存；旧羊档保持羊。

## 原版依据与验证

[Banished Wiki: Farming](https://banished-wiki.com/wiki/Farming) 说明可把至少10头的畜群拆分来扩展牧场；[Pasture](https://banished-wiki.com/wiki/Pasture) 说明牲畜可分散到多场提升数量和产出。本作固定6×6、羊12/牛10的容量及群体直接划拨是明确适配。

- node tests/pasture-split.js：头数/进度、在途原产品、真实牧作后继续繁殖、旧档与反复读档、桥梁和途中通路变化、拆场回待安置池、非法/陈旧方案。
- node tests/pasture-split-ui.js：方案/取消/幂等、变化与陈旧回调、焦点、无逐帧寻路；属于DOM验证。
- 关联检查继续覆盖牛羊原流程、存档、用工、经营流水和基础启动。离线 Canvas 使用实际分群前后状态和现有 drawEconomyFieldPart，确认两个独立场地分别显示6+6羊或5+5牛。

复用既有原创羊、牛和牧场素材，不生成新图。没有真实浏览器/手机验收或生产部署，未把离线预览说成设备试玩。既有两项无关施工几何基线失败仍不在本片宣称修复。
