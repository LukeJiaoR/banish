# 衣食、贸易与新产业

本批以用户指定的 [Banished Wiki](https://banished-wiki.com/) 为玩法参考，补全能操作的生产与发展链。数值与地图规模为本作适配；不复制原版贴图。

## 开始玩

1. 食物分肉类、蔬菜、主食。渔码头/猎人产肉，采集屋产蔬菜，农田产主食。三类共享原食物总仓容；只要总量够，缺一种也不会额外挨饿。旧档食物一次性归入主食，总量不变。
2. 猎人带肉同时带回皮革。裁缝铺 1 人，从仓库取 2 皮革制作 1 件衣物（受教育 2 件）；缺皮时可用 2 羊毛。市民逐日领取，衣物用一年，户外受冻累积降低 40%，住房与燃料仍需要。
3. 水边建贸易站，设置待售目标。商人实际从仓库搬入，贸易库存不再供居民消费。总容量 2000；目标改为 0 可让商人搬回。拆除前要搬空，避免库存无声消失。
4. 商船首次约一季到访，停留一季，之后约每年到访。选货物、数量及付款资源，面板显示实际需付数量。只使用已经搬入的待售品，以物易物，没有金币。
5. 羊每只 600 贸易单位，果树种子 2500。种子永久解锁所有果园；普通买入物资先进入贸易库存，再由商人搬回。
6. 羊牧场先移入至少两只羊，1 人照料后缓慢繁殖、剪毛。保留目标 2–12，超额才屠宰，羊产肉与毛，不产皮。拆牧场时存羊转待安置数量。
7. 果园需购种并照料约四年才长成，此后秋收，冬天未收果实损失。果实按用户三分类并入蔬菜类。

一级分类下展开实际已有的二级建造/操作菜单；返回分类会取消当前未提交操作，已确认的采集任务保留。

## 与原版及用户简化的区别

- [裁缝](https://banished-wiki.com/wiki/Tailor_(Building)) 的单岗、皮革/羊毛制衣及教育增产关系保留；当前先用一种衣物库存，不区分三档衣服。
- [种子](https://banished-wiki.com/wiki/Seeds) 保留一次购买永久解锁；本批先支持一种果树。
- [羊](https://banished-wiki.com/wiki/Livestock) 与 [牧场](https://banished-wiki.com/wiki/Pasture) 保留购买、繁殖、毛肉用途；动物按牧场群体数量管理。
- [果园](https://banished-wiki.com/wiki/Orchard) 保留多年成熟与季节收获，尚未加入树龄衰退/重植及多果种。
- [市民](https://banished-wiki.com/wiki/Citizens) 的饮食多样性在原作主要关联健康。本作按用户要求先作为幸福度基础统计，暂不以此改变生产效率或增加新死亡条件。
- 商船固定提供本批关键解锁，价格、货单与到访节奏是明确适配；孤立水面也允许贸易站，暂不模拟船只水路航行。
- 现有非矿物满仓溢出规则仍存在；食物三分类不会获得三份额外仓容。有限矿物保货规则保留。

本批按用户要求先完成内容与配套美术，合并前仅基本启动、明显阻断及存档安全快速检查，完整回归不作为此阶段门槛；真实浏览器和平台适配留给后续试玩反馈。

开发期快速排错记录：新局可启动并保存重载；两名成人、仓库/贸易站/裁缝的48游戏小时流程中，20木真实从居民仓库转入待售库存，2皮革制成1件衣物并由居民领取。交易API的羊/果种购买与牧场安置、解锁及贸易库存保存重载一致。美术以实际绘制函数的离线Canvas预览查看，未作浏览器试玩或全量回归。
