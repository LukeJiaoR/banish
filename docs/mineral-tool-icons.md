# 0.3.9 矿石工具与统一资源图标

基线main：`7dc21ca16326584d530b1701cc0e701012fd0522`（0.3.8）。本批只修操作入口和表达，不改变地图、矿藏、产量、仓储、调度或存档。

## 修复

- 工具栏前部增加「采石采铁」：点击/沿线拖拽标记灰岩或锈色铁矿，散工真实开采再送仓。悬停提示实际矿种，非矿格显示无可采矿。
- 采矿不拆建筑、树木或道路。拆除仍能拆建筑/道路，但不操作天然资源；树木用砍伐。旧内部demolishAt接口保留，UI使用安全分流。
- 砍伐与采石采铁放在工具栏最前，窄屏无需先横滚到尾端寻找基础资源操作。原取消采运标记、聚焦按钮、面板下输入保护保留。
- `G.RES.iconAsset`是资源图片注册源，资源栏和建造成本使用同一helper、同一PNG和同一备用符号。纯文字悬浮提示使用统一资源名称，不再拿另一个emoji表示同种资源。采矿操作是镐与文字，不冒用库存“工具”数量图标。

## 验证

- 矿石资源UI 13项注册/HTML合同；输入和取消UI共25项，包含真实点击标记→advanceSim开采→石/铁各入库10，以及重复点击、拖拽、中断、弹窗、误拆防护、道路拆除与建筑实际退款。
- 独立采集链审计19个微型fixture及8个固定种子实际步进：石铁ID未串、无重复收货；跨夜、无工具减产、不可达、读档和满仓边界均按现有合同运行。
- 用户反馈“石头远”有地形证据，不归咎于操作：0.3.8的128种子中28个在起点14格内无可达石头、5个24格内无石，最近可达石头最大49.2格。近矿生成候选另行实验，**没有混入本批**。
- 同样，草地/秋季水面、人物呈现、地图尺寸与专业建筑人效属于后续独立批次，不以本批声称已完成。

## 保留边界

既有散工先树后矿，长树队列可能延后采矿；现在可观察采运进度并取消树标记。满仓时现有交付仍会丢弃多出产物，包括有限矿藏；这是真实风险，已保留复现，下一独立批处理保货与等待空间，不通过送库存绕过。
