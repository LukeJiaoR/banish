# 施工优先级（0.3.40）

想先修通木桥、完成过冬住房或关键生产屋时，可以在原有工地用工面板点“优先施工”。不必先暂停所有旧工地，也不会增加总劳力或改变单工效率。

## 派工规则

- 只有未完成工地能设为“优先施工”或“恢复普通”。新工地和旧档默认普通；同级仍按原放置顺序，不因反复点击争抢第一名。
- 自动调度先考虑优先工地，再考虑普通工地。优先工地必须有真实可达的工作入口，才会拿走可用工人。优先级不保证配足四人；粮食救急、手动采运的散工预留、学生/教师约束沿用。
- 已经在普通工地的人，不会被立即中断。他先做完当前施工小段或一棵树的清场，送清实际货物，然后才会在正常接新任务的边界转入仍有空位、未暂停且可达的优先工地。
- 在途当前货批需要为调配收尾时，先用同一真实寻路检查可达优先目标，再使用既有保全标记。隔河不可达的优先工地不会仅凭排位改变普通工地的货物规则；途中修通道路后，在实际交仓前再检查一次，先保住这批货再交接，不逐帧寻路。满仓或断路则仍保留当前货物；过夜休息和载入不会复制产物。卸净即销毁该货物对象，后续普通采集不继承标记。不把有货者当成空闲劳力。
- 两座同为优先的工地不会互相抢现有人手。优先目标暂停、拆除、完成或恢复普通后，不再触发新转岗；已完成的小段与材料不会回退。
- 暂停优先于排位：可以提前给暂停工地设优先，但恢复施工之前不会派工。未完成的木桥仍不可通行，优先级和暂停均不改变水面碰撞。
- 改级别不再扣建材，不增加工时贡献，不改变房屋升级退款规则。工地完成后移除施工优先标记。

## 存档和界面

只增加工地的布尔优先字段，不保存新的跨工地预订队列。旧档缺省为普通；非法类型或把优先字段放在成品建筑上的档案，在替换世界前拒绝。仍沿用原存档合同：实际货物、进度、已付款保存，完整任务与路线在载入时重建，不能把未做完的小段伪作已完工。

面板两颗固定意图按钮避免一次双击先升后降。已有暂停按钮、当前人数、缺人原因和全镇只读人力概览保持。刷新不重建聚焦按钮，换村/读取同 ID 新实体/关闭页面/工地完工后的旧按钮不能修改新状态。
