# 可选山地新局与地形存档（0.3.75）

跟踪：[Issue #85](https://github.com/LukeJiaoR/banish/issues/85)。本片只接入完整可玩的山地新局；隧道另片实现，当前 UI 明示未接入。分支文档不是已发布证明，以普通 PR 合并为准。

## 原版依据与本作边界

- 用户指定的 [Banished Wiki：新局地图设置](https://banished-wiki.com/wiki/Tutorials/First_Year_on_Hard_Difficulty#Map_Settings) 描述地形选择与开局选址；[Tunnel](https://banished-wiki.com/wiki/Tunnel) 描述山地通道及山体高度要求。原版地形选择有经营后果，不只是界面标签。
- 本作仍为 128×128 地图、现有四季/48日历与库存经济；新增选项是“原地形”或“山地（开局保障谷地）”。没有气温、高程气候、地图尺寸选择、山矿规则或重量物流。
- 随山脊轮廓起伏的视觉高度、阈值和 41×37 保底谷地是明确的本作适配。原版未承诺此固定谷地或本片资源预算，不据此声称精确复刻原版地图生成。

## 选择、生成与可玩保障

原地形仍默认，经典/困难预设可分别搭配山地。修改地形会取消待确认的新局；只有两阶段最终确认成功才替换当前村。无效参数或生成/可达验证失败保留旧世界、随机数、ID、进度和存档。

同种子、地形版本和预设生成相同初始地形、人口与物品；这不承诺中途载入逐步重放。山地只在新局生成一次：

1. 独立噪声标记不可通行山体，地表水和山体不重叠；采集石/铁仍是另外的可采露头。
2. 在固定有限的 5×5 候选中心中，按需要改变的水/山地格最少排序，种子散列与固定坐标打破平局；不偷偷重抽种子。
3. 明确整理一片 41×37 谷地（1517格，约全图9.3%），放入7×10水塘、有限木石铁与成熟食物林。谷地外不再按开局需要整平。所有原料都要真实采运，没有入库赠送。
4. 通过普通生产 API 放置唯一初始储物车与家庭后，在真实车占地上做验证。五块2×2住房用地及采集/林业/柴火/铁匠/渔业/矿业用地，在影子占格中同时存在，各有可达入口；出生居民、仓库所有入口和原料共享同一个无穿角可达分量。影子建筑不会进入游戏，也不永久预留土地，玩家自行规划和施工。
5. 木、石、铁分别核算。预算包含五木屋、采集小屋、林业屋、伐木屋、铁匠、渔屋、矿井和采石场，以及五木屋一年柴火与一轮30工具补充的未受教育产量；当前总额为木462/石184/铁25，再扣预设已有木石铁。至少24棵可达成熟食物树与建材木分开计量，原料在48步可达范围内。保障的是存在可行经营空间，不会替玩家建设，也不保证任意乱建或迟迟不采集仍生存。

山体始终阻步行、农牧果园/墓园/普通建筑、道路、桥头、树木种植和鹿群生境。山地图放置建筑前复核占地内居民的真实出口，不能隔山驱逐；围死房屋不把新生儿降落在不可走格。道路继续按现行真实时间成本寻路；本片没有隧道捷径或完工通道。

## 显示与操作

山体用原项目提示词风格的新原创暖岩/薄雪材质，Canvas 负责精确64×32地格和沿边缘到内部隆起的共用山面顶点。高起表面与暴露岩壁共用绘制/命中多边形，鼠标和触摸的建造、道路与选区都指向实际山体格；不会穿过可见岩壁在后方空地误建。相邻山格隐藏内部侧壁、共享边缘顶点；视觉高度不写进存档或改变通行。山体参与原有深度排序，前后人物和建筑沿实际脚点排序。工具悬停会标出阻挡山格。

纹理是手绘生成的近似连续材质，并非数学无缝贴图；雪面存在轻微重复边界，保留原始生成来源与诚实 QA 说明，见[美术记录](art-assets/mountains.md)。

## 旧档、新档与实货

- 旧根v1 / mapVersion 0、1继续原生成算法，已有村庄绝不重新生成山地；经典新局仍写根v1与原配置形状。
- 山地必须写根v2 / mapVersion 2，保存完整 water/rock/mountain 数组、原始起点与明确新局来源。载入用共同的空世界分配器恢复实际地形，**不再次调用生成、保底补料或开局库存发放**。已挖走的矿、砍下树木、路、工地、库存与随身实货按现有规则恢复。
- 旧程序看到根v2会拒绝，而不是把山体无声改回平地。玩家应在新版本读取山地档；导出文件备份仍可用。
- 错误的新地形维度/类型/范围/交叠、山中实体与无效来源会原子拒绝，不通过重新选址/传送掩盖坏档。实际库存归属与新地形校验同时保留；可步行采矿格上的死亡物资等合法实货不能被新规则误拒。
- 已接建材/工业/生活货继续使用原有所有权与退仓流程；本片没有第二套物流。当前存档原本不保存完整任务/随机数位置，载入会重排路径任务，此限制不冒充确定性回放。

## 验证口径

针对性检查包括重复及边界种子、经典/困难、实际车与影子建筑占地、分别足量原料/保留森林、坏档原子拒绝、真实旧版本存档、根v2旧程序拒绝、实际携货/死亡与建材、界面过期确认、夏冬绘制和高起表面命中。

离线 Canvas 图片、模拟和 DOM 检查不是浏览器或手机试玩。未做生产部署。具体运行数字与独审结论在验收记录/PR中按实际结果补充，不提前宣称通过。
