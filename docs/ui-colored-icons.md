# 彩色界面图标

资源、建造分类/项目与系统入口复用原有 24px SVG 线稿，在下方增加封闭填色层。木材/食物暖金、石材/工具灰蓝、铁/柴火陶橙、植物苔绿、果肉莓红、暖衣灰紫，共六组共享色板；无需下载图片、调用生成服务或更换系统 emoji。

颜色表示物品本身。缺料边框和文字、选中背景、键盘焦点继续独立表达状态；警报、勾选、关闭、导航、拆除和速度符号仍继承上下文颜色。成本仍显示完整材料名和数量，例如木屋的「木材 16 石头 8」。图标尺寸、点击区域、可访问文字和玩法不变。

强制颜色模式隐藏填色并恢复继承描边，让系统高对比度方案接管。未知图标名安全回退为房屋。
