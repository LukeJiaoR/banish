# 学堂、真实到校与毕业（0.3.32）

## 玩家可见规则

- 沿用10岁入学、1位教师、20名学生；到入学年龄时没有可达且有教师的空位，孩子成为未受教育工人，之后不重新入学。现有成年劳力与已毕业身份不变。
- 学生和教师真实步行到学堂入口。师生都到校、健康且不饥饿，才按实际经过的游戏小时累计学习；通勤不计课时，夜间回家休息。教师在远处挂着岗位不算授课。
- 毕业须同时达到17岁和1344课时，每天最多6小时。1344＝7年×48日×4小时，是本作适配值，给正常通勤留余地；不是Wiki公布的原版课时数。幸福、工具和受教育生产倍率不会加速学习。
- 在读学生不接砍树、采矿或专业成人岗位；旧任务残留会清理，已经携带的真实货物仍先送仓。毕业后恢复成人劳力并获得既有受教育生产收益，不另加一层倍率。
- 生病、饥饿或教师暂未到场只暂停学习。教师岗位空缺或原校被拆，会寻找另一所有教师、空座且可达的学堂；没有合适位置则保留学籍和课时等待恢复。不会因一次失师自动永久辍学。
- 新施工挡路或挤离原入口时重新寻路，不计隔空课时；原入口不可达也可选其他合法入口。课堂挡风，沿用室内寒冷积累，不替代有柴的住房。

## 学籍管理

学堂详情显示教师分配/实际到场、在校人数/20座、名单与学习规则；点击名单可查看已经进屋的师生。学生详情显示总课时、本日学习、年龄与未毕业原因，以及缺教师、满座或路线问题。

“结束学业并工作”先展开后果说明，再确认永久退学：该居民成为未受教育工人，失去毕业生产收益且不能重新入学。取消保持原课时和学籍；确认后重复点击无效。切换居民、关闭面板、弹出其他窗口、开始新村或加载新档后，旧按钮回调不能操作新对象，即使居民ID相同。

失师自动保留学籍是本作的可恢复改编，避免旧档因岗位重新调度批量遭受不可逆损失；需要劳力时由玩家逐人明确决定。

## 存档兼容

保存总课时、本日课时与对应日期，读档后重新走实际路线，当日上限不会重置刷课。旧档没有课时字段时，在读学生按10至17岁的原有年龄进度折算；例如16.99岁只差不到2小时，不要求重新读多年。既有成年工人不会返校，已受教育居民保持毕业。

负值、超过课程/每日上限、非数值或未来日期的损坏记录原子拒绝，当前小镇不变。和既有存档合同一致，任务与路径并不逐帧保存，载入后重新调度。

## 表现与验证

沿用现有原创学堂、成人/儿童行走图：在途中正常显示，实际进入课堂后隐藏室内人物，避免教师在门口做砍伐动作；地图点选跳过室内人物，可从学堂师生名单打开其详情。本片没有重绘学堂或新增第三方素材。

定向模拟覆盖真实到校、在读劳动隔离、每日上限、缺师转校、病饿暂停、施工挤离后恢复、拆校后复学、满座/不可达、年龄与课时双条件、旧档临近毕业及重复退学。DOM事件测试覆盖确认/取消、持续焦点刷新、旧控件/旧世界失效和真实加载同ID新档；另验基本启动、存档、人物绘制与邻近UI。单种子三年开局诊断为15人→18人、出生3人、死亡0人，不代表所有数值情境。

离线调用实际绘制函数和DOM测试不是浏览器/手机试玩；当前浏览器启动仍受环境socket限制。本片无生产部署。

## 原版依据

[Banished Wiki：School House](https://banished-wiki.com/wiki/School_House) 描述每校1名教师、20名学生，10岁入学、17岁或更晚毕业，远距离影响学业；失师者寻找别校，成为劳工后不能重新入学。本片继承上述因果和现有年龄设计；固定课时/每日上限、失师无空位时保留学籍和逐人退学确认是本作适配。
