# 商人差异与回访订货（0.3.50）

自0.3.53可另行启用 [单规则到港自动购买](auto-trade.md)；默认关闭。订货本身仍只预约带货，手动购买始终可用。

## 玩家选择

贸易站保持1名工人、真实备货/运回、2000共享容量和以物易物。在现有交易面板查看本次商人、现货、收货范围以及实际价格。未来每船不再永远带齐所有物资：可以等普通货单，也可以在这位商人停靠时指定一笔下次回访货物。

三位固定商人各有目录：

- 河湾杂货商：现有全部10种可买货物（0.3.52加入早熟豆类种子），接受现有全部付款资源，包括三类食物。第一船仍带完整旧目录；后续普通回访随机带其中4种。
- 山路物资商：煤、钢工具、铁、皮革，普通到访带其中2种；拒收三类食物，可用其他待售资源付款。
- 绿篱种子商：果树/卷心菜/早熟豆类种子，普通到访带其中1种；同样拒收食物。

数量仍受每船上限约束，目录并不表示本次都带来了。综合商仍负责牲畜贸易，首船解锁机会保留。永久种子买过后不能重复购买或新订货。

## 一笔单次订单

1. 只有商人仍停靠，才能给这位商人登记、更换或取消下一次回访的订单。每站、每位商人各保留一笔，数量从1到该货物原有每船上限。
2. 登记不扣任何资源，也不预留付款库存，不保证届时买得起。重复登记相同内容不多创建一份。
3. 其他商人中途到访不会履约或清掉这笔订单。是**同一位商人的下一次回访**，不是下一船。
4. 对应商人到达时，把指定货的现货设为所订数量，订单即完成带货并从待回访清单移除；该货本次按订货价出售，其他普通货仍按原价。订货本身没有替玩家买入：默认仍须手动成交，只有另行明确启用的到港自动规则可能按设定付款。
5. 订货单价按 `floor(普通单价 × 1.25)`。例如煤6→7、钢工具10→12、羊600→750、牛800→1000、种子2500→3125；主食1→1。实付资源数仍按总价值除付款单价向上取整。
6. 到货后没有买完的库存只在这次停靠期间存在，离港即随船带走，不自动生成下一笔订单。可在本次停靠时另订下一轮。若等待期间从别处买到了永久种子，到货不会重复解锁或自动扣款，可不购买这批货。

别家待回访订单以及离港后的订单仍可查看；只有对应商人再次在场时可改下一轮。订货货物到达后的本船溢价保留至离港，不能通过取消下一轮订单、换付款物或读档恢复原价。

## 时序和旧档

新贸易站第一船沿用建成后12日。以后到访间隔16日，停留12日，三位商人轮流，所以同一位正常约48日回访。预期回访日以当前船实际到达计算；时序若被跳过会顺延，不承诺下一船履约。这是本作48日历年的节奏适配。

已有在港商人视为综合商，现有库存、剩余停靠时间和正常价格保持；原有在途备货/运回任务不因商人分类改变。没有在港商人的旧站保留已保存的下次到访日期，并从完整综合商首船开始。原有在港船离开后接入新的轮换。不会倒补漏过的商船或赠送订单。

保存商人身份、实际到达日、剩余库存、本次订货价标记、下一轮次及各商人待回访订单。多次载入不会重填已购买的现货、再次带同一笔订单或扣资源。订单对象经过校验重建，不保留输入对象引用；未知商人、越目录订单、非法数量或货单被拒绝且当前世界不变。

报价和实际成交共用模拟层规则，均核实收货范围、实际单价、现货、待售付款和2000容量（包括已背出在途占位）。旧世界、拆除建筑或已更换商船的旧面板回调不可作用于新船。

## 原版规则与适配

[原版贸易](https://banished-wiki.com/wiki/Trade) 的专营商人、有限货单、食物收货限制、停靠期订货及同一商人再次到访关系保留；[原版订货计价](https://banished-wiki.com/wiki/Currency) 的25%加价后截断小数保留。

三位固定身份、3类商人、4/2/1随机货种、16/12/48日节奏、每商人一笔单次指定数量，以及当前10种商品与原有价值均为本作简化。未实现原版全部商人类型、长期循环订单或真实船只水路航行；自动购买自0.3.53加入到港单规则版。沿用当前地图和画面素材，无新资产。

## 验证

10个定向核心检查覆盖首船/后续有限货单、订单替换取消不预付、同人回访一次履约、部分购买后的溢价存档、付款拒收、原版截断价格、种子重复保护、旧在港货单与旧下次日期、两站隔离、旧世界回调、损坏档原子拒绝。

真实模拟从第12日至第60日，经过物资商、种子商、冬季与中途存读档，只有综合商回访带到7煤，全程不自动扣石；随后手动购买只付7石。沿用容量片的7个在途占位/同刻交易/满仓退货检查，并复核种子、牛场、账本、挑战、启动和存档。

15个订货DOM/模拟通路检查、既有17种子UI/10牛场UI/6分群UI均通过，覆盖价格/拒收、无预付、切船旧按钮、切世界和焦点保持。UI定向DOM验证不等于真实浏览器或手机试玩。无生产部署，不以本片通过声称已修完历史无关基线问题。
