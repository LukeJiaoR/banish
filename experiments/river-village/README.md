# 河畔村落分层渲染实验

本实验使用实际 Banish `G.frame`、等距相机和既有 PNG；不使用 AI 生成图冒充运行画面。只新增独立入口和实验文件，不修改 `index.html`、`js/`、源 PNG、默认世界生成或存档。A 是方向参考，不是本实验已达到的画质。此版本仅为技术验证，未获美术验收。

## 本地使用

在仓库根目录运行 `python3 -m http.server 8000`，用浏览器打开 `http://localhost:8000/river-village.html`。页面支持原版/组合、五个独立开关、缩放、拖动、回到初始镜头。默认所有效果关闭。页面只创建暂停的人工布景，没有载入/写入游戏存档或生产模拟；并不代表实际游玩中的村落。

五项试验：土路与草地交界、透明轮廓近似投影、脚点接触暗部、局部浅水/岸石、混合树冠。混合树冠复用果园树，树木脚点与原深度排序保持；它不改变树种/资源/碰撞逻辑。地面装饰无交互意义。投影烘到实验地面缓存，不能当作正确的动态光照或树冠间遮蔽。

## 可复现离线证据

需要 Node.js 与 `@napi-rs/canvas`（仅验证工具依赖，浏览器游戏不依赖它）。运行：

`node experiments/river-village/render.cjs /tmp/banish-river-village-evidence`

输出 desktop、narrow、far 三镜头 × baseline / 五个单效果 / combined，共21张；另有对照拼图与 report.json。所有截图均来自 native Canvas 离线执行实际游戏渲染函数，不是浏览器截图。390px画布不代表实体手机验收。

测试包括全关闭与未安装 adapter 的 main 像素一致、开关重置回原像素、强制重建像素一致、世界/游戏序列化状态不变、树根脚点不变、建筑树木绘制深度单调、缓存预算。当前32×32固定场景地面缓存2,349,312像素，额外投影缓存279,376像素（1,117,504字节）；并非整个应用峰值内存。

已有回归：`node tests/terrain-presentation.js`、`node tests/citizen-presentation.js`、`node tests/smoke.js`。这些不是完整浏览器交互或性能验收。

## 明确未完成

- 当前 VM Chromium 启动权限阻断；未通过浏览器交互与截图验证，不绕过安全设置。实体手机帧率、长期内存与触摸体验未测。
- 土路仍直且有拼片感；需要专门的地表过渡遮罩/边缘素材，不能继续堆噪声代替美术。
- 树冠仍来自少数既有资产；需要有设计差异的树型、低矮灌木、岸草、庭院装饰，兼顾留白。
- 现有西式木屋、红瓦与A中式灰瓦院落有实质差异；没有替换资产或声明已复刻A。
- 既有素材带烘焙光与阴影，新增投影只是可开关近似，不能改变光向或真实处理遮挡。不能凭本样板决定全局尺度、昼夜光照或引擎迁移。
- 只面向固定夏季人工样板。不是可直接装到任意游戏世界的生产插件；修改世界后需完整重建，实验故意禁用局部地表更新以避免半透明叠加残留。
